# 画面のめぐり方

[手引きの目次](README.md)

画面は1枚の Web アプリで、左に行き先、上に帯、真ん中に中身、右に詳細の欄がある。画面の部品は
`src/ui/wiki.html`、動きは `src/ui/app.js.html` と `src/ui/js-*.html` (場所ごとに分けてあり、`wiki.html` が順につなぐ)、見た目は `src/ui/app.css.html` にある。

## 左の行き先

| まとまり | 行き先 | 何をする画面か | 手引き |
|---|---|---|---|
| — | ホーム | あなたの番と前進。開いたときに最初に出る (設定で変えられる) | [ホームとポイント](home-and-game.md) |
| 管理するもの | 文書 | 登録した正式版の文書の一覧。「文書を登録する」もここ | [文書と確認依頼](documents-and-reviews.md) |
| 管理するもの | やること | 一覧・ボード・工程表・集計・捨てたもの | [やること](tasks.md) |
| 進行中 | 改訂中の版 | 直している途中の版の一覧。改訂版を作る・まとめて記録する | [文書と確認依頼](documents-and-reviews.md) |
| 進行中 | 確認依頼 | 反映してよいか尋ねているものの一覧 | [文書と確認依頼](documents-and-reviews.md) |
| 期間で進める | 作業期間 (スプリント) | 期間ごとの計画・残りの量の推移・期間ごとに終えた量。**オンのときだけ出る** | [期間で進める](scrum.md) |
| 期間で進める | 困りごと (障害物) | 進みを妨げているもの。**オンのときだけ出る** | [期間で進める](scrum.md) |
| 困ったとき | 使い方 | 画面の中の手引き。絞り込みと目次がある | 下の「使い方」 |
| 困ったとき | 使われ方 | どこがよく使われているか | [使われ方](usage.md) |
| 困ったとき | 要望・不具合 | みんなで話せる相談板 | [要望・不具合](inquiries.md) |
| この道具 | 設定 | 自分の設定とチームの設定 | [設定](settings.md) |

やること・改訂中の版・確認依頼・困りごと・要望・不具合には、まだ閉じていないものの数が出る (チーム全体の数)。
期間で進める画面の名前は、自分の設定「言葉の表し方」で一般の言葉とスクラムの言葉を切り替えられる。

左の並びと中身の間の掴み手を引くと幅が変わる。二度押しで元の幅に戻る。

## 上の帯

| 部品 | 内容 |
|---|---|
| 題名と「?」 | 主な画面 (ホーム・文書・やること・確認依頼・工程表・使われ方・設定) の見出しの横の「?」で、使い方の該当する節を開く |
| 版の切り替え | 文書を開いているとき、どの版 (正式版・改訂版) を見るかを選ぶ |
| 変更を記録 / 直接編集を退避 | 改訂版に記録していない変更があるとき「変更を記録」。正式版が Docs で直接なおされていたとき「直接編集を退避」 |
| 元のファイルを開く | Docs / Sheets / Slides 本体を開く |
| 全画面 / リンクをコピー | 文書を読んでいるときに出る (下) |
| 探す | 文書・やること・確認依頼などを題名で探す (下) |
| 鈴 | 画面の中の知らせ。「全部読んだ」と、ブラウザのデスクトップ通知の受け取り |
| 自分の顔 | 表示する名前・はじめの案内をもう一度出す・週の上位への参加 (ポイントがオンのとき)・手元から動かす道具を落とす |
| 明るさ | 端末の設定に従う → 明るい → 暗い の順に切り替える。この端末に覚える |

## 文書を開いたとき

文書の一覧から1つ開くと、上にタブが出る。

| タブ | 内容 |
|---|---|
| 本文 | いまの中身。「読む」と「直す」を切り替える。「直す」は改訂版でだけ使える (Markdown で書き換えて保存) |
| 改訂の履歴 | 変更の記録の系統図 (誰が・いつ・何を)。2つを選ぶと左右2列の差分が出る |
| この文書の改訂版 | この文書から作った改訂版の一覧と「この文書の改訂版を作る」 |

### 全画面とリンク

文書を「読む」にしているとき、上の帯に **全画面** と **リンクをコピー** が出る。

- **全画面** — 左の並びと上の帯を隠して本文だけを広げる。Esc か「全画面を閉じる」で戻る。ほかの画面へ移っても戻る。
  ブラウザの全画面 (Fullscreen API) は Apps Script の枠の中で断られるので使わず、画面の中で広げている
- **リンクをコピー** — その文書を全画面で開くリンク (Web アプリの URL に `?doc=<fileId>&full=1` を付けたもの) を写す。
  写せないときは、選んで写せる欄にリンクが出る。リンクに秘密は入らない。開いた人がその文書を見られないか、
  登録されていない文書なら、開かずに知らせてホームのままにする

## 探す (Ctrl+K)

上の帯の虫眼鏡か **Ctrl+K (Mac は ⌘K)** で、どこからでも探す欄が開く。

- 探せるもの: 正式版の文書・やること・確認依頼・改訂中の版・報告・使い方の節。期間で進めるがオンなら困りごとも
- 合わせるのは**題名・番号・状態だけ**。人の名前やアドレスでは探せない (人を探す道は作らない)
- 一覧は欄を開いたときに1回 (60秒ごと) 取り、打つたびには手元で絞る。`#12` のように番号でも探せる

## キーボード

字を打っている欄の外で効く。

| キー | 操作 |
|---|---|
| Ctrl+K / ⌘K | 探す |
| / | やることの絞り込みの欄に移る |
| N | やることを作る |
| ? | キーボードで使える操作の一覧を出す |
| Esc | 右の欄や小窓・全画面を閉じる |

## 右の欄

やること・確認依頼・報告などを押すと、右に詳細の欄が開く。やることは**まず読む形で開き**、右上の鉛筆で書き換える
(触っただけで中身が変わることはない)。欄と中身の間の掴み手で幅を変えられる。

## 使い方

左の「使い方」は画面の中の手引きで、節ごとに図が付いている。

- 本文の上の欄で**絞り込み**ができる。打った字を見出しか行に含む節だけが出る
- 本文の右に**目次**が出る (狭い画面では隠れる)
- 管理者向けの節には「管理者」の札が付く。隠しはしない (誰に頼めばよいかが分かるように)
- 探す (Ctrl+K) からも節へ飛べる

## 断られたとき

押した操作が断られると、帯 (または一覧の欄) に理由が出て、その下に1行 **「次にすること: …」** が出る。

- 「混み合っています」のときだけ **[もう一度]** が出る。押すと同じ操作を1回だけやり直す (混み合っただけで、何も変わっていない)。
  開き直した欄から送り直すか、元のボタンを押し直したら、[もう一度] は消える (両方押して同じものが2つできないように)
- 「途中まで済みましたが、混み合って続きができませんでした」は、途中まで書けている。[もう一度] は出さないので、一覧で確かめる
- 英語で「混み合い」や「回数の上限」が出たときも [もう一度] は出さない。しばらく時間をおいて、一覧で確かめる
- 時間がかかりすぎて止まったとき (時間切れ) は [もう一度] を出さない。途中まで済んでいることがあるので、一覧を開き直して
  済んでいないかを確かめてから押し直す (そのまま押すと同じものが2つできることがある)
- 権限が無い・消えた・ほかで先に直された・入れた内容が足りない、も、それぞれ誰に頼むか・どこから戻せるか・開き直す・
  入れ直す、を言う
- 英語の断り (Apps Script の実行時のエラー) は日本語に言い換えて出す
