# 使われ方

[手引きの目次](README.md)

左の「使われ方」は、どこがよく押され、どの画面がよく開かれているかを見る画面。使われていない所を見つけて直すための
もので、人を見張るためのものではない。実装は `src/core/Usage.gs`。

## 何を数えるか

台帳の `usage` シートに残るのは **「日・種類・場所・回数・押した人」の5つ** だけ。

- 種類は `view` (画面を開いた) と `action` (押した) の2つ
- **残すのは「その日に何回押したか」まで。押した順番・時刻・文書や書き込みの中身は残さない**
- 押した人はサーバ側で決める (`Session.getActiveUser()`)。画面から受け取ると名乗りを詐称できるため
- 名前 (id) を付けていない場所は数えない。一覧の行やカードは1つずつではなく、種類でまとめて数える
  (やること・報告の行 / 進捗ボードのカード / 工程表の棒 / 文書 / 変更の記録 / 関わりの札)
- 押すたびには送らず、画面側でまとめてから送る。一度に受け取る場所の数には上限 (60) がある
- 使い方の節を開いた回数も数える (場所の名前は `guide-<id>`)。目次・絞り込みで1件になったとき・「?」・探すで開いた
  ときだけで、送って通り過ぎただけでは数えない

## 誰のぶんが見えるか

- 場所ごとの合計は誰でも見られる
- 人ごとの数は本人と部下のぶんだけ ([人と工数](people-and-effort.md#見える範囲))。よく使っている人の並びも同じ範囲

## 画面

期間 (直近7日 / 30日 / 90日) と、誰のぶんを見るかを選ぶ。

- **数えた回数** — 4枚のカードに、同じ長さの直前の期間との増減 (±% と矢印) を添える。前の期間に記録が無ければそう出る
- **よく押された場所・よく開かれた画面** — 順位表。前の期間との増減を小さく添える
- **この期間に開かれなかった画面** — 左の行き先のうち、一度も開かれなかったもの。期間で進めるがオフなら、その画面は除く
- **曜日ごと** — 月曜から日曜までの7本の棒。時刻は残していないので、時間帯は分からない
- **CSV で保存** — 今見ている期間と対象の、日・場所・人ごとの数。**見られない人の行は入れない** ので、画面の合計とは
  合わないことがある (名前を空にして数だけ残すと、見られない人が1人のときその人の記録がそのまま読めてしまうため)。
  保存できないとき (Apps Script の枠の中で断られたとき) は、字をそのまま写せる形で出す

## 止める・残す日数

| 何を | 誰が | 設定 |
|---|---|---|
| 自分のぶんを数えない | 本人 | 自分の設定「自分の使われ方を記録する」(`usage.self`) |
| チーム全体の記録を止める | 管理者 | チームの設定「使われ方を記録する」(`usage.enabled`) |
| 残す日数 | 管理者 | チームの設定「使われ方を残す日数」(`usage.keepDays`、既定180日、90〜365日) |

画面で直近90日まで見るので、90日より短くはできない。古い行は記録のついでに落とす (日が読めない行は落とさない)。
行の数は「日 × 場所 × 人」で頭打ちになる。
