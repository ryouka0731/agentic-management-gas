# 設定

[手引きの目次](README.md)

左の「設定」は **自分の設定** と **チームの設定** の2つに分かれている。

| | 誰が変えるか | 置き場 |
|---|---|---|
| 自分の設定 | 誰でも、自分のぶんだけ | スクリプトプロパティ `MYPREF:<小文字のアドレス>` (JSON) |
| チームの設定 | 管理者だけ (ほかの人には今の値が見えるだけ) | スクリプトプロパティ `PREF:<key>` |

- 変えられる項目は `src/core/Prefs.gs` の **`PREFS_SCHEMA()` が唯一の定義**。画面は `apiPrefs` の一覧から欄を組み、
  写しを持たない。下の表はこの定義から作った (`test/docs.test.js` が、定義の全項目がこの頁にあるかを見ている)
- 欄ごとに保存する。**「既定に戻す」** でその項目を消すと、最初の値に戻る
- 値が無い・読めない・範囲の外なら既定値 (= 今の動き) として読む。既定値は今の定義 (`ADVICE_RULES()` / `STALE_STEPS()` /
  `HOME_DUE_DAYS()` / `USAGE_KEEP_DAYS()` / `REPORT_TEMPLATES()`) から取る
- **自分の設定も UserProperties ではなくスクリプトプロパティに置く。** 通知は送る側の権限で、キューは持ち主の権限で
  走り、受け取る人の UserProperties は読めないため。そのぶん、スクリプトの持ち主はエディタで他人の設定
  (止めた通知の種類・最初の画面) を見られる。どの端末で開いても同じになる
- 設定を変えても、変更の履歴 (`change_log`) には残さない

型: `bool` はオン・オフ、`int` は範囲のある整数、`enum` は選択、`steps` は小さい順の3つの整数、`calendar` はカレンダーの ID
(`…@group.calendar.google.com` の形。空は「決まっていない」)。

- **最初に出す画面** は、文書のリンク (`?doc=…`) から開いたときには使わない (その文書を出す)
- **言葉の表し方** は期間で進める (スクラム) まわりの言葉を切り替える。対応は [期間で進める](scrum.md#2通りの言葉)
- **通知メール** は全部止められる。止めても画面の中の知らせ (鈴) は止まらない。「確認を頼まれた」を止めた人には、
  設定の画面に断りが出る (ホームの「あなたの番」と鈴で確かめてほしい)
- 日報の形 (3節 / 今日だけ / 見出し無し / 自分の形) はホームの「日報にコピー」の横で選ぶ。これは設定の画面ではなく、
  本人の UserProperties に覚える ([ホームとポイント](home-and-game.md#日報にコピー))
- **集中のしかた** は既定でオフ。「今から始める」をオンにすると、やることに入口が出る。オフのあいだは、時間の知らせと
  集中の音も使わない (入口が出ない)。記録はあなたにだけ見える。詳しくは [集中のしかた](focus.md)
- **自分の曲** は、YouTube / SoundCloud の再生リストのリンクを貼ると、集中しているあいだに公式の再生機で流せる。
  「読み込む」を押すまでは何も読み込まない。詳しくは [集中のしかた](focus.md#自分の曲を流す)
- **楽しい演出** は3つとも既定でオフ。オンにした人の画面にだけ出て、ほかの人には見えない。音は鳴らさない。
  - 打つと盛り上がる — 字の欄で打ち続けると、欄の近くに「12 COMBO B」のような数と段 (C → B → A → S) が出る。
    10・20・30・50・100 で大きな字 (COMBO x10 / MEGA HIT / ON FIRE x30 …) が出る。5 回以上続けたあとで消すと
    「COMBO BREAK」。1.5 秒打たないと数え直す。日本語の変換中は数えず、決めたときに数える。探す欄と絞り込みの欄では出ない
  - 言葉に反応する — 「完成」「リリース」で 🚀 と SHIPPED!、「ありがとう」「好き」で 💖 と LOVE ♡、「承認」「OK」で NICE!、
    「締切」「至急」で HURRY!
  - 済ませたらお祝い — 反映した (SHIPPED!)、やることを済ませた (CLEAR!)、承認した (NICE!)、確認を頼んだ (SENT!)、
    記録した・保存した (小さく SAVED)。失敗したときは出ない
  - 打った字・カーソルの位置・欄の中身には触らない。演出は1秒ほどで消える。OS で「視差効果を減らす」(動きを減らす)
    にしていると、紙吹雪や枠の光は出さず、短い字の札だけを出す
- **推し** は既定でオン (既定のキャラはタク。ほかの飾りと違うが、要らなければ外せる)。オフにすると出ない。オンのあいだは右上の自分の顔から開く欄に「推し」が出て、自分で作ったキャラクターの絵・名前・口調・
  せりふを決められる。済ませたときに左下の吹き出しでほめ、ホームであいさつする (`oshi.home` で止められる)。
  最初からいるキャラ (タク・イツキ・つじっぴ・いっくん・りょうか・さと美) か、自分で作ったキャラ (5人まで) から `oshi.char` で選ぶ。自分のキャラの絵が無い表情は
  `oshi.fallback`、最初からいるキャラの 2頭身・等身は `oshi.style`。
  `oshi.mood` (既定オフ) をオンにすると、やることが滞ったときに推しがしょんぼり・むっとする ([機嫌](oshi.md#機嫌))。
  `oshi.peek` (既定オン) は、何も操作していないときに右下からひょっこり出て1つだけ伝える ([ひょっこり](oshi.md#ひょっこり))。
  絵の作り方と入れてよい絵は [推し](oshi.md)
- **実績** は既定でオン。通算で開いた日・済ませた数・はじめて使った機能で実績 (バッジ) が取れ、推しのなつき度は
  1 + 取った実績の数になる。あなたにだけ見え、順位も続けた日数も無い。取ったときの知らせは `ach.cheer` で止められる。
  チームの「目標」・共有カレンダー・チームの「使われ方を記録する」がオフ (決まっていない) あいだ、それを使う実績は「この環境では取れません」と出て、
  クリアの数に入らない。自分の設定で止めているものはクリアの数に入れたまま、オンにすれば取れると添える。
  一覧と決まりは [実績](achievements.md)
- **予定に入れる** は既定でオフ。オンにすると、担当のやることを期限の早いものから共有カレンダー「番頭の予定」に並べる
  (1日1回、ホームを開いたときに組み直す。設定の「予定を組み直す」でもすぐ組める)。会議と重ねず、番頭が入れた予定しか
  触らない。予定の名前はカレンダーを共有している人に見えるので、見せたくなければ `calendar.title` を「集中」にする。
  詳しくは [予定に入れる](calendar.md)
- **Gemini のメモを 1 日 1 回自動で取り込む** は既定でオン。番頭を開いたとき1日1回、あなたが開ける会議の Gemini のメモの「次のステップ」を
  やることにし、作ったときは短く知らせる。オフにしても「予定に入れる」の節の「Gemini のメモを取り込む」で取り込める。Gemini のメモは
  Google Workspace の機能なので、個人の Gmail では何も起きない
- **会議の時間** は既定でオフ。オンにすると、自分まわりの欄を開いたときに、あなたのカレンダーの会議の時間 (今週・今月・今半期) を出す。
  数はあなたにだけ見え、会議の名前や相手はどこにも残さない。詳しくは [会議の時間](calendar.md#会議の時間)
- 画面の明るさは上の帯で切り替え、その端末に覚える

### 思いがけない当たり・ノリノリタイム・自分へのご褒美

「パチンコのように盛り上がる仕掛けがほしい」という声から入れた。くじの害 (当たるかどうかに振り回される・
やめにくくなる) を持ち込まないよう、**楽しいところだけ**を取り出してある。どれも自分の設定で、最初はオフ。
オンにした人の画面にだけ出て、ほかの人には見えない。音は鳴らない。

- **思いがけない当たり** (`luck.on`) — やることを済ませた・反映した・承認した・記録したときに、たまに (8回に1回ほど)
  真ん中に「大当たり！」と、3つ揃ったリール・金色の紙吹雪・ねぎらいの一言が出る。集中を始めただけでは引かない。
  集中しているやることを済ませたときは、集中の SUPER COMPLETE!! だけを出す。
  当たるのは**1日3回まで**で、前の当たりから**30分は空ける**。失敗した操作では出ない。
  当たっても**ポイントも機能も何も増えない** (見た目の演出だけ)。推しをオンにしていると、推しも「当たり」に驚く
- **ノリノリタイム** (`luck.on` に含む) — 1時間のうちに3つ済ませると、15分のあいだ画面の縁がほんのり金色に光り、
  「済ませたらお祝い」(楽しい演出) の字が大きくなる。右下の小さな札「ノリノリタイム」は × で隠せる (隠したことは
  その端末に覚える。集中の置き場が出ているときはその上に出る)。残り時間は出さず、時間が来たら黙って終わる
  (「終わりました」とは出さない)
- **自分へのご褒美** (`luck.reward`) — 右上の自分の顔から開く欄の「自分へのご褒美」で、自分にあげたい小さな
  ご褒美 (好きなコーヒー・15分の散歩など) と、そのポイント (1〜50) を自分で決めて並べる (20個まで)。
  たまったポイントと交換すると、残りが減って「交換した記録」に残る。**最後の交換は5分のあいだ取り消せる**。
  - たまる数の数え方は1つに決めてある。ポイントとレベルがオンで、週の上位に**参加している**ならそのポイント。
    参加していなければ、**済ませたやること1件を1**と数える。どちらも初めて開いたときから数え、台帳から数え直すので、
    済ませたやることを開き直すと減る (交換したぶんより減ったら、残りは 0 で交換できない)
  - やること1件を1と数えるときは、**初めて開いたあとに作ったやること**だけを数える (前からあったものを閉じ直しても
    増えない)。担当のいないやることを閉じた人のぶんは、**1日5件まで**
  - 参加する・やめる・ポイントとレベルがオフになる、のどれかで数え方が変わると、単位が変わるので**そこから数え直す**
    (画面に「数え方が変わったので、ここから数え直します」と出る)。前の交換は「前の数え方で ◯ 回 (◯ ポイント)」とまとめて残る
  - 交換した記録は新しいほうから30件まで残し、古いものは合計にまとめる (残りは変わらない)
  - ご褒美と交換した記録は**あなたにだけ**見える (台帳にも置かない)。お金でも会社からの賞品でもなく、
    給与や評価とも関係ない
- 動きを減らす設定 (OS の「視差効果を減らす」) では、リール・紙吹雪・縁の光は出さず、短い字の札だけになる

次のものは**わざと作らない**。お金や賞品との交換・くじ (当たるとポイントや機能が増えるもの)・外れの演出・
「あと少しで当たり」(ニアミス)・当たらないと失うもの・続けた日数と、それが途切れたときの演出・
当たりの回数や交換の順位。当たる確率を上げる方法もない。

| `goals.enabled` | 目標 (OKR・MBO・KPI) を使う | bool | オフ | [目標](goals.md)。オフのあいだは左に「目標」が出ない |
| `goals.period` | 目標を立てる区切り | enum | `half` (半期ごと) | 半期ごと / 四半期ごと。立てた目標の期は変わらない |
| `goals.fyStart` | 年度の始まる月 | int | 4 | 1〜12。期はこの月から数える。変えても、立てた目標の期の日付は動かない (目標ごとに立てたときの月を残す) |
| `cowork.enabled` | 作業雑談部屋を使う | bool | オフ | [作業雑談部屋](cowork.md)。オフのあいだは左に出ず、誰がいるかも見えない。部屋の一覧は同じ節の欄で決める (10まで) |
| `calendar.shared` | 予定を入れる共有カレンダー | calendar | (空) | 「共有カレンダーを作る」で作るか、ID を貼る。[予定に入れる](calendar.md#管理者がすること) |

### 設定の画面にある、ほかのチームの設定

`PREFS_SCHEMA()` の外にあり、それぞれ専用の API で変える。どれも管理者だけ。

| 項目 | 置き場 | 内容 |
|---|---|---|
| チームの毎月の目標 | `TEAM_MONTHLY_GOAL` | ホームの「チームの前進」の目標。0 で消す |
| 期間で進める (エージェンティックスクラム) | `SCRUM_ENABLED` | 既定オフ。[期間で進める](scrum.md) |
| 目指すところ・終わったと言える条件 | `SCRUM_PRODUCT_GOAL` / `SCRUM_DEFINITION_OF_DONE` | 期間で進めるがオンのとき |
| ポイントとレベル | `GAME_ENABLED` | 既定オフ。[ホームとポイント](home-and-game.md#ポイントとレベル-既定オフ) |
| 最初からいるキャラのプロフィール | `OSHI_PROFILE:<キャラ>` | 推しの頁で Lv ごとに分かるプロフィールとクリアのお祝い (JSON)。管理者にだけ出る。[推し](oshi.md#プロフィールとクリア) |
| 成果の数 | (読むだけ) | チーム全体の数を週ごとに。3人に届かない週は出さない。[管理](admin.md#成果の数) |
| コマンドキューの状態 | (読むだけ) | 誰が動かしているか・最後に回った時刻。1時間より前に止まっていれば引き継ぎ方が出る。人のアドレスを含むので管理者にだけ見える |

## 項目を足すとき (開発者向け)

1. `PREF_GROUPS_()` のどこかの組に足す (key の先頭の語が組の名前になる)。範囲と既定値を書く
2. 読むところは `prefGet_(key, email?)` だけ、書くところは `apiPrefSet` だけを通す
3. 通知メールの種類を足したら `NOTIFY_KINDS()` に足し、`notify(to, subject, body, kind)` に kind を渡す
   (渡さないと、止めた人にも届く)
4. この頁の表に足す (`test/docs.test.js` が見ている)
