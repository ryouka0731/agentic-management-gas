# 実績

[手引きの目次](README.md)

番頭を開いた日 (通算)・済ませた数・はじめて使った機能で **実績 (バッジ)** が取れる。取った実績の数で
[推し](oshi.md)のなつき度が上がり、推しのプロフィールが少しずつ分かる。**この環境で取れる実績を全部取ると「クリア」**で、
推しの頁にクリアの節が出る (プロフィールが全部分かり、キャラのお祝いの言葉と、決めてあればお祝いの動画)。**既定はオン**で、自分の設定の「実績」で止められる ([設定](settings.md))。

## 決まり

- **通算で数える。** 開いた日は、東京の暦日ごとに1日 (1日に何回開いても、タブを2つ開いても1日)。
  **続けた日数は数えない**。毎日来ないと取れない実績は無い
- **一度取った実績は消えない。** やることの完了を取り消しても、使われ方の記録が古くなって間引かれても (180日)、取った印は残る
- **見られるのはあなただけ。** ほかの人の実績を見る道は無く、順位も無い。管理者・上長にも見せない
- まだ取っていない実績は **???** と出る。数のある実績は、いちばん近い1つにだけ「あと 3 件で…」と手がかりが出る。
  「はじめて」の実績は名前も手がかりも出ない (まとまりの名前だけ)
- **推しのなつき度 = 1 + 取った実績の数**。段は Lv1〜4 がよそよそしい、Lv5 でなれてきた、Lv15 でなついた、Lv25 でべったり、Lv35 で家族。実績は消えないので下がらない。
  実績の前から推しを使っていた人は、そのとき届いていた段より下にはならない (その段から始まる。その段に届いただけでは「段が上がった」と言わない)
- 手元の道具からの命令で反映したものは、命令を置いた人の「反映した」になる

## この環境では取れない実績

使い方や設定によっては、取れない実績がある。実績の頁では札 **この環境では取れません** と、どうすれば取れるかを出す。
**クリアまでの数とまとまりごとの数には入れない** (取れない実績が残っていても、取れるものを全部取ればクリア)。

| 実績 | 取れないとき | 取れるようにするには |
|---|---|---|
| いっしょに (6つ)・はじめての「反映した」「承認した」 | 番頭を使っているのがあなた1人 (共有ドライブなら投稿者以上、マイドライブなら持ち主と編集する人、と上下関係の名簿で数える) | ほかの人と使う (確認や承認をする相手が要る) |
| 目標を立てた | チームの設定「目標 (OKR・MBO・KPI) を使う」がオフ | 管理者がオンにする |
| 予定に入れた | 共有カレンダーが決まっていない | 管理者が共有カレンダーを決める |
| Markdown で保存した・日報をコピーした・探す (Ctrl+K) を使った | チームの「使われ方を記録する」がオフ | 管理者がオンにする |

**取れないことにするのは、チームの設定と使い方の事情だけ。** 自分の設定で止めているもの (自分の「自分の使われ方を記録する」・
「今から始める」・「推しに応援してもらう」・「やることを予定に入れる」) は、クリアの数に入れたまま、
「自分の設定「◯◯」をオンにすると取れます」と手がかりだけを出す (自分で切るだけでクリアに届くと、クリアは消えないので戻せない)。

1人で使っているかは、Drive の共有 (共有ドライブの投稿者以上、マイドライブの持ち主と編集する人) と、台帳にほかの人が出てくるか
(上下関係の名簿・確認依頼を出した人と確認を頼まれた人・返事・やりとり・担当・使われ方) の両方で見る。どちらかにほかの人がいれば1人ではない。
グループ・ドメイン・リンクで共有しているとき (何人いるか分からない) と、読めないときも1人とは言わない。

- **取った実績は、あとで取れなくなっても消えず、数にも入る**
- 「手元の道具を使った」はいつでも取れる (だれでも入れられる)。まだのうちも、取り方の手がかりを出す
- 取れる実績の残りが **3つ以下** になると、残りの名前と説明を出す (何が足りないか分かるように)
- **クリアは一度届けば消えません。あとから取れる実績が増えても、クリアはそのまま** (ほかの人が加わった・チームの設定をオンにした、など)。
  実績の頁は「クリアしました」と出し、あとから取れるようになった数を添える (取るたびに「全部取りました」とは言わない)。
  まだクリアしていない人は、取れる実績が増えたぶんクリアが先に延びる
- 1人で使っていると、取れる実績が少ないぶん最高の Lv も低い。推しのプロフィールで、その Lv より上の項目は「クリアで分かる」と出る

## 見るところ

- 右上の自分の顔から開く欄の **実績** — まとまりごとの取った数、全部の実績 (取った日)、推しのなつき度 (Lv)、次に近い実績、クリアまであと何個か
- ホームの **最近の実績** — Lv と、最近取った3つ (設定の「ホームに出すもの」で止められる)
- 取ったとき — 画面の隅に小さく知らせ、推しが「実績を取った」のせりふでお祝いする。段が上がったときは
  「なつき度の段が上がった」のせりふと、上がった段の絵。最後の実績を取ったとき (クリア) は「実績を全部取った」のせりふ。
  推しをオフにしていれば、知らせは「Lv ◯」だけで、推しの段やプロフィールは添えない (実績の頁も「Lv ◯」だけ)。
  知らせの数え方は、実績は「◯ 個」、推しのプロフィールは「◯ 項目」。楽しい演出の「済ませたらお祝い」がオンなら大きな字も出る。
  どれも `ach.cheer` (実績を取ったら知らせる) を止めると出ない。焦点は奪わず、動きを減らす設定では動かない

全部を数え直すのは開いたときだけ (このときだけ開いた日を数える)。実績に関わる操作をしたあとは、その操作で変わりうるものだけを
数え直す。実績の頁を開いたときも数え直すが、その日に「まだ」と分かった「はじめて」は読み直さない (次に開いた日にまた数える)。

### いっしょに

| | 実績 | 取れるとき |
|---|---|---|
| 🚀 | はじめて届けた | 自分が出した確認依頼が 1 件反映まで届いた |
| 🛰️ | 10件届けた | 10 件 |
| 🌠 | 50件届けた | 50 件 |
| 👀 | はじめての返事 | ほかの人の確認依頼に 1 件返事をした (承認・差し戻し・中身のあるコメント。同じ依頼には1日1件) |
| 🔎 | 10件見た | 10 件 |
| 🦉 | 50件見た | 50 件 |

### はじめて (どれも1回で取れる)

| | 実績 | 何で確かめるか |
|---|---|---|
| 📝 | 改訂版を作った | 台帳の改訂版 (作った人) |
| 📨 | 確認依頼を出した | 台帳の確認依頼 (出した人) |
| 🎉 | 反映した | 反映したときに残る変更の記録 (反映した人) |
| 👍 | 承認した | 台帳の確認 (承認) |
| 💾 | Markdown で保存した | 使われ方の場所 `md-save` |
| 💬 | やりとりを書いた | やることのやりとり・報告への返事 |
| 📮 | 報告を書いた | 台帳の報告 (要望・不具合) |
| 📋 | 日報をコピーした | 使われ方の場所 `report-copy` |
| 🔥 | 集中を始めた | 集中のしかたの記録 |
| 🧭 | 仕事のスタンス診断を受けた | 診断の結果がある |
| 💖 | 推しを選んだ | 設定の「使うキャラ」を選んだ (使われ方の場所 `oshi-choose` も見る) |
| 🎯 | 目標を立てた | 台帳の目標 |
| 📅 | 予定に入れた | 予定を組んだ覚え |
| 🧰 | 手元の道具を使った | 手元の道具から置いた命令の覚え (14日ぶん) |
| 🔍 | 探す (Ctrl+K) を使った | 使われ方の場所 `search-open` (探した結果を開いた) |

使われ方の場所で確かめる4つ (Markdown で保存・日報をコピー・探す・推しを選ぶ) は、**使われ方を記録しないとき**
(チームの `usage.enabled` か自分の `usage.self` がオフ) には取れない。推しを選んだは設定にも残るので、既定以外の
キャラを選べば取れる。

## 置き場

| 何を | どこに |
|---|---|
| 通算で開いた日と取った印 | スクリプトプロパティ `ACH:<小文字のアドレス>` = `{days: {n, last}, got: {実績の key: 取った日}}` (日は東京の暦日 `yyyy-MM-dd`) |

前の形 (開いた日を `ACH_DAYS:<アドレス>` に、取った印を時刻で置いていた) は読むときに今の形にし、次に書くときに `ACH_DAYS:` を消す。

実績のための記録の表は作らない。数は台帳と、今あるスクリプトプロパティと使われ方から数える。スクリプトの持ち主は
エディタでスクリプトプロパティを見られる (設定と同じ)。定義は `src/core/Achievements.js` (`ACHIEVEMENTS()`) が唯一。
