# 予定に入れる

[手引きの目次](README.md)

「いつ・どのやることを・どれくらいの時間でやるか」を、番頭がチームの共有カレンダー「番頭の予定」に入れる。
**既定でオフ**で、オンにした人のぶんだけ入れる。

## 何をするか

- あなたが**担当**の、開いているやることを並べる (捨てたもの・済んだものは入れない)
- 並べる順は **期限の早いものから**。期限の無いものは最後。同じ期限なら優先度の高いもの、それでも同じなら番号の小さいもの
- 要る時間は、予定の工数 (人日) − 実績 (人日) を時間にしたもの (1人日 = 8時間)。担当が複数いるときは**頭数で割る**
  (工数の数え方と同じ。[人と工数](people-and-effort.md))。工数が入っていない・もう使い切ったものは、1つ分 (下の「1つの予定の長さ」) だけ入れる
- 入れるのは、設定の「予定を入れる時間」の中だけ (既定 9:00〜18:00、月曜〜金曜)。祝日は見分けないので、休みの日は
  自分のカレンダーに終日でない予定を入れておくか、組み直したあとに消す
- **会議と重ねない。見るのは、あなたの既定のカレンダーと共有カレンダーの会議だけ** (ほかに登録しているカレンダーは見ない)。
  共有カレンダーでは、番頭の印の無い予定 (チームの定例など) と、ほかの人の番頭の予定のうちあなたがゲストのものを会議とする。
  終日の予定・断った予定・「空き」にした予定は空いているものとする (「空き」かどうかは、Google が読み取りの口を
  用意しているときだけ見分ける。見分けられないときは埋まっているものとする)
- 会議の前後と、番頭の予定どうしのあいだは 10分空ける (会議が終わったその分から始めない)
- 長いやることは「1つの予定の長さ」(既定 45分) に分ける
- 今日を含めて「先の何日ぶんまで」(既定 5日) の勤務日まで。それより先には入れない。1回に入れるのは 20 件まで
  (上限で止めたときは「1回に入れられる数で止めました」と添える。続きは次に組み直したときに入る)
- 期限までに入りきらないもの (空いている時間が尽きたもの) は、設定の欄とホームのカードに「期限までに入りきりません」と
  添える (責めない)

## いつ組み直すか

- **1日1回、その日に初めてホームを開いたとき** (裏で組む。失敗してもホームは出る)
- 設定の「自分の設定」→「予定に入れる」の **「予定を組み直す」** を押したとき (続けて押せるのは 60秒に1回まで。
  待つあいだはボタンが押せない)

組めなかった日 (共有が外れていた・混み合っていた) は組んだ日に数えないので、次にホームを開いたときにもう一度試す。
2つの画面 (タブや端末) で同時に組み直すと、あとのほうは「別の画面で組み直しています」と断る (予定が二重にならない)。

組み直すと、あなたの**これから始まる**番頭の予定を消して入れ直す。いま続いている予定と、終わった予定は残す。
**あなたが直した番頭の予定 (動かした・名前を変えた・ゲストを足した) も消さずに残し**、会議と同じく避けて組む
(作ってから1分より後に変わったものを「直した」と見る)。要らなくなったら Google カレンダーで消す。
番頭が触るのは、**番頭があなたのために入れた予定だけ** (予定に見えない印を付けてある)。ほかの人の予定や、
人が入れた予定は消さない。

台帳には何も書かない (カレンダーそのものが記録)。最後に組んだ時刻だけを覚える。

## 使い始める

1. 管理者に、共有カレンダー「番頭の予定」を作って、あなたを **「予定の変更」** の権限で共有してもらう (下の「管理者がすること」)
2. 左の「設定」→「自分の設定」→「予定に入れる」で **「やることを予定に入れる」** をオンにする
3. 同じ欄の「予定を組み直す」を押す。ホームに「今日の予定」のカードが出る

初めて使うとき、Google からカレンダーを使ってよいかを尋ねる画面が1回だけ出る (このアプリが Google カレンダーを
読み書きできるように足したため)。許可すると使えるようになる。

共有されたカレンダーがまだあなたのカレンダーの一覧に無いときは、番頭が登録する (Google カレンダーの左の一覧に
「番頭の予定」が出る)。「カレンダーで開く」からも登録できる。

## 管理者がすること

1. 左の「設定」→「チームの設定」→「予定に入れる」で **「共有カレンダーを作る」** を押す。押した管理者の Google カレンダーに
   「番頭の予定」ができ、チームの設定に入る。あるカレンダーを使うときは、その ID (`…@group.calendar.google.com`) を貼って
   「この ID にする」を押す (押した管理者が開けるカレンダーだけ入れられる)
2. 出てきた **「共有の相手を足す」** を押すと、Google カレンダーのそのカレンダーの設定の頁が開く。
   「特定のユーザーまたはグループと共有する」で、使う人を **「予定の変更」** の権限で足す
   (「予定の表示 (すべての予定の詳細)」だと見るだけで、番頭は予定を入れられない)。頁が開かないときは、
   Google カレンダーの左の一覧で「番頭の予定」の「︙」→「設定と共有」を開く
3. 作り直すときは「外す」を押してから作る。外しても、カレンダーとその中の予定は消えない (Google カレンダーで消す)

拡張サービス (Calendar API) は使わない。標準の CalendarApp だけで動く。

## ほかの人に見えるもの

- 共有カレンダーを共有している人には、**予定の名前と時刻が見える**。既定の名前は「#12 規程の改定」の形
- 見せたくなければ、設定の「予定の名前」を **「集中 (番頭) とだけ出す」** にする
- 予定の説明には、やることの番号・番頭の URL・「番頭が組んだ予定です。組み直すと変わります」を書き、最後の行に
  「番頭: <あなたのアドレス> #<番号>」と書く (番頭が自分の入れた予定を見分けるための印。共有している人には見える)
- あなたの既定のカレンダーは読むだけで、何も書かない。会議の名前を共有カレンダーに写すこともない

## やめるとき

設定の「やることを予定に入れる」を**オフにすると、これから先の番頭の予定を消す** (いま続いている予定・終わった予定・
あなたが直した予定は残す)。そのあとは何も入れない。消せなかった予定があると、設定の欄に「消せなかった予定が n 件あります
(カレンダーで消してください)」と出る。そのときも設定はオフになる。

## 会議の時間

自分の設定の「会議の時間を出す」(`calendar.meetings`、既定はオフ) をオンにすると、自分まわりの欄 (上の帯の自分の顔) を
開いたときに会議の時間が出る。数えるのは**あなたの既定のカレンダー**で、今週 (月曜から)・今月 (1日から)・今半期 (4〜9月 / 10〜3月)
に分けて出す。どれも**今までのぶん** (これからの会議は入れない)。

- 会議として数えるのは、参加者があなたを含めて2人以上で、あなたが断っていない予定。終日の予定は数えない
- 同じ時間に会議が2つ重なっていれば1つ分 (重なった時間は二重に数えない)
- 読むのはあなたのカレンダーだけ。数はあなたにだけ見え、会議の名前や相手は番頭のどこにも残さない
  (下の「Gemini のメモの取り込み」で取り込んだ会議だけは、名前と時刻が台帳に残る)
- 30分ほど覚えておくので、会議を足してもすぐには変わらない。カレンダーを読めないときは欄が出ない
- Gemini のメモを取り込んだ会議があれば「うち議事録のある会議」の時間 (今半期) も添える

## Gemini のメモの取り込み

設定の「予定に入れる」の **「Gemini のメモを取り込む」** を押すと、直近7日の会議の Gemini のメモ (Drive の Google ドキュメント) の
「次のステップ」の1行ずつを、やることにする (1日1回、番頭を開いたときにも裏で取り込む)。担当は行に書かれた名前 (「@名前」「名前:」
「名前さんが」など) が人の名前に当たればその人、当たらなければあなた。本文には会議名・日時・メモのリンク・元の行が入る。
見るのはあなたが開けるメモとあなたのカレンダーだけで、同じメモ・同じ題名のやることは二度作らない。**Gemini のメモは Google Workspace の
機能**なので、個人の Gmail のアカウントでは見つからず、何も起きない。会議に結び付かなかったメモは「会議不明」として取り込む。

## うまくいかないとき

| 出る知らせ | すること |
|---|---|
| 予定を入れる共有カレンダーがまだ決まっていません | 管理者に、チームの設定で共有カレンダーを作ってもらう |
| 共有カレンダー「番頭の予定」を開けません | 管理者に、あなたのアドレスを「予定の変更」の権限で共有してもらう |
| 共有カレンダー「番頭の予定」に予定を入れられません (見るだけの共有になっています) | 管理者に、「予定の変更」の権限で共有し直してもらう |
| 「やることを予定に入れる」がオフです | 設定でオンにする |
| カレンダーが混み合っています。あとでもう一度組み直してください | 少し待ってから「予定を組み直す」を押す (入れかけた予定は消してある) |
| 別の画面で組み直しています | ほかのタブ・端末で組み直している。少し待ってから開き直す |
| さっき組み直したところです。あと n 秒待ってから押してください | 待ってから押す |
| 共有カレンダー「番頭の予定」はまだあなたのカレンダーに入っていません | 「予定を組み直す」を押すと入れる |

開発する人向けの細部 (印の名前・覚え書きの鍵・実機検証 `debugVerifyCalendar()`) は [docs/dev/calendar.md](../dev/calendar.md)。
