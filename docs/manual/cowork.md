# 作業雑談部屋

チームで決めた Google Meet の会議や Slack のハドル・チャンネルを「部屋」として並べ、いま誰がそこにいるかを
番頭の画面で見られるようにする。**既定はオフ。** 管理者が設定の画面でオンにしたときだけ、左に「作業雑談部屋」が出る。

## 何が起きるか

- 部屋の「入る」を押すと、その部屋 (Meet / Slack) が**新しいタブで開き**、番頭の部屋のカードにあなたの名前が出る
- **話す・画面を見せるのは Meet / Slack の中**で、番頭は Meet / Slack に何も頼まない (番頭は外の API を呼ばない)。
  部屋の中のこと (誰が参加できるか・録画・記録) は **Meet / Slack の決まりと設定**に従う
- 「出る」を押すと名前が消える。Meet / Slack の画面はそちらで閉じる (番頭からは閉じられない)
- 番頭の画面を開いているあいだ、1分ごとに「まだいる」の合図を送る。番頭のタブを閉じる・眠らせると合図が止まり、
  **最後の合図から2分で名前は消える**。Meet の画面を見ていて番頭のタブが裏に回っていても30分は合図を送り続け、
  それを過ぎると止める (開いたまま忘れた人をいつまでも「いる」にしない)。番頭のタブに戻ればまた出る
- いられるのは1つの部屋だけ。別の部屋に入ると、前の部屋から名前が消える

## 見えるもの・残るもの

- 見えるのは「入る」を押した人の**表示名**だけ (表示名が無い人は「名前未設定」)。アドレスは画面に出さない
- 見られるのは、番頭を開けるチームの人。**オフのあいだは誰にも見えない**
- **番頭は誰が入ったかを記録しない。** いる印はスクリプトのキャッシュ (しばらくで消える置き場) にだけ置き、
  台帳・使われ方・最近の動き・メールには入れない。あとから「誰がいつ入ったか」を調べる道は無い。
  [実績](achievements.md)「作業雑談部屋をのぞいた」も、入ったかではなく、左の「作業雑談部屋」の頁を開いたこと (ほかの頁と同じ使われ方) で数える
- 自分の設定「部屋にいるとき『集中中』を添える」(`cowork.showFocus`、既定オフ) をオンにすると、
  [集中のしかた](focus.md) で集中しているあいだ、名前の横に「集中中」が出る。名前と「集中中」は入ったときと、そのあと10分ごとに
  引き直す (切り替えてすぐ出したいときは入り直す)
- 番頭を2つのタブで開いて別々の部屋に入ったときは、あとから入った部屋にいることになる (古いタブの合図では部屋を移らない)

## 管理者がすること

1. 設定の画面の「チームの設定」→「作業雑談部屋」で「作業雑談部屋を使う」(`cowork.enabled`) をオンにする
2. 同じ節の「部屋を足す」で、部屋の名前とリンクを入れて「部屋を保存する」。部屋は10まで、名前は30字まで

使えるリンクは次の3つだけ。打つとその場で使えるかを知らせる。

| 部屋 | リンクの形 |
|---|---|
| Google Meet の会議 | `https://meet.google.com/abc-defg-hij` (呼び名の `https://meet.google.com/lookup/…` も使える) |
| Slack のハドル | `https://app.slack.com/huddle/T…/C…` |
| Slack のチャンネル | `https://<ワークスペース>.slack.com/archives/C…` |

- Slack Enterprise Grid の、組織ごとの場所 (`<組織>.enterprise.slack.com` など) のリンクには対応していない
- `https://` で始まらないもの、似た名前の場所 (`meet.google.com.example.com` など)、番号やユーザー名の付いたもの、
  Slack の発言へのリンクは断る
- 番頭が覚えるのはリンクの中の会議のコードと id だけで、開くリンクはそこから組み直す (貼った字そのものは残さない)
- オフのあいだも部屋を用意できる。部屋を外すと、その部屋にいた人の名前も消える
- Meet の会議に誰が入れるか (組織の外の人・ノックが要るか) は Meet の会議の設定で決める。番頭では変えられない
