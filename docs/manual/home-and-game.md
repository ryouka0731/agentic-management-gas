# ホームとポイント

[手引きの目次](README.md)

ホームは開いたときに最初に出る画面 (自分の設定「最初に出す画面」で変えられる)。カードは6つあり、どれを出すかは
自分の設定「ホームに出すもの」で選ぶ。設計は [ホームの設計](../superpowers/specs/2026-10-14-home-design.md)・
[5つの依頼](../superpowers/specs/2026-10-19-five-asks-design.md) にある。

## 守っていること

- 草は**本人のぶんとチームの合計だけ**。部下を含めて、他人の草は出さない
- **連続日数・最長記録は出さない** (途切れたときに意欲が下がる)
- 最近の動きに**人の名前を出さない**
- ポイントは**既定でオフ**。人事の評価には使わない

## あなたの番

あなたが動く番のものを種類ごとに並べる。押すとそのものを開く。

- 確認を頼まれた確認依頼
- 「直してほしい」が返ってきた自分の確認依頼
- 担当のやることのうち、期限が近いもの・過ぎたもの

「期限が近い」とみなす日数は既定で3日。管理者がチームの設定 (`home.dueDays`、1〜14日) で変えられる。
手元からは `node agent.mjs mine` で同じものが見られる。

## 改善のヒント

仕事の進め方を良くするヒントを、多くて3件出す。番頭が台帳の数から**決まった規則で**出すもので、AI に問い合わせては
いない。見るのはあなたのぶんだけ (担当のやること・あなた宛ての確認・あなたが作ったやること) で、ほかの人の数や名前は出ない。

| 規則 | 既定で出る条件 | ボタン |
|---|---|---|
| 確認を待たせています | あなた宛ての確認を3日以上返していないものが1件以上 | 確認依頼を開く |
| 期限切れが溜まっています | 担当の期限切れが3件以上 | 期限切れで絞ったやること |
| 抱えすぎています | 作業中の担当が5件以上 (同時に進めてよい数の目安は3) | ボードを開く |
| 見積もりと実際がずれています | 30日で片づけた担当のうち工数を書いたものが3件以上あり、その半分以上が予定の倍以上かかった | 工程表を開く |
| 同じ作業を繰り返しています | 30日で同じタグ (または題名の先頭の語) のやることを5件以上作った | そのタグで絞ったやること |
| 使い方の問い合わせが続いています | 30日で「使い方が分からない」の報告が3件以上 (**管理者にだけ**。件数だけで誰が出したかは言わない) | 要望・不具合を開く |

- 1件ごとに理由の数字と、次に開く画面のボタンが付く。「期限切れを見る」で開いた一覧は「期限切れだけ ×」か見え方の
  切り替えで絞りが外れる
- 「今週は出さない」で、その週はこの端末に出さない (端末の `localStorage` に覚える)。次の週にまだ当てはまればまた出る
- 規則ごとのオン・オフと数は、管理者がチームの設定 (`advice.*`) で変えられる。規則・重み・言葉の唯一の定義は
  `src/core/Home.gs` の `ADVICE_RULES()`
- 手元からは `node agent.mjs advice`

## 草 (アクティビティ)

日ごとに動いた数を、色の濃さで直近53週ぶん並べる。「あなた」と「チーム」を切り替えられる。

## 最近の動き

チームで最近あったこと。誰がしたかの名前は出さない。

## チームの前進

- 今週片づけたやることの数と、今週反映した確認依頼の数
- 今月片づけた数と、**チームの毎月の目標**までの進み具合。目標は管理者が決める (0 で消す)。人ごとには出さない

ほかに、はじめての人向けの「はじめの5歩」と、今日片づけたもの (本人にだけ見える。件数は大きく出さず、題名を並べる) が出る。

### 日報にコピー

今日片づけたものの横の「日報にコピー」で、日報の形に当てはめた文を写す。

| 形 | 中身 |
|---|---|
| 3節 (既定) | ✅今日やったこと / 📅明日やること / ⛔️困っていること |
| 今日だけ | ✅今日 |
| 見出し無し | 今日のぶんだけ |
| 自分の形 | `{今日}` `{明日}` `{困りごと}` を差し込める字を自分で書く (2000字まで) |

- 明日: 自分が担当の未完了で、期限か開始日が明日以前のもの (期限の早い順に10件)
- 困りごと: 自分が出した未解決の困りごと (期間で進めるがオフなら空)
- 自分で形を選んでいない人は、チームの設定 `report.defaultKind` の形になる。形の唯一の定義は `REPORT_TEMPLATES()`
- 手元からは `node agent.mjs report [three|today|plain|custom]`

## ポイントとレベル (既定オフ)

管理者が設定の画面でオンにしたときだけ出る。

- **ポイントの付き方** — やることを片づけると1点。重いもの (大きさが5以上か予定工数が1人日以上) は +2、作ってから
  14日以上たって片づいたものは +2、分けたやることの最後の1つは +1。担当が複数なら頭数で割る
- **確認にもポイント** — ほかの人の確認依頼に返したやりとり1件で1点。自分の依頼への確認は数えない。同じ依頼には
  1人1日1点まで (数稼ぎをさせない)
- **レベル** — レベル n に上がるのに要る累計は 5 × n(n+1)/2 点。いちばん高かったレベルだけを覚える (取り消しでレベルは下がらない)
- ポイントは台帳から毎回数え、保存しない。月曜にゼロから数え直す (週ごと)
- **称号** — 本人にだけ見える。はじめの一歩 / 10件・50件・100件片づけた / 重いやることを片づけた / 待たせていたものを
  片づけた / 確認を10件返した / 分けたやることを最後まで片づけた。まだのものは薄く「あと N 件」と出る
- **週の上位** — 上位3位まで。自分の顔のメニューで「週の上位に参加する」を選んだ人だけが載る (既定は参加しない)。
  アドレスは返さない。上位にいない人に自分の順位は返さない
- **先週のチーム** — チーム全員の先週の合計 (名前なし) を先々週と比べる。終わった週だけを使い、見る人のほかに2人以上
  ポイントのあった週だけ数を出す (1人だとその人の数がそのまま分かるため)

この機能はほかの人の数を見せる唯一の例外で、上の守りは崩さない。理由は [CLAUDE.md](../../CLAUDE.md) の
「画面から呼べる関数」にある。
