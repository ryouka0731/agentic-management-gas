# 集中のしかた

やることに取りかかるのを助ける仕掛け。いちばん難しいのは**始めること**なので、気合いに頼らず、
**始めたことをその場で返す**。全部が自分の設定で、**最初はオフ**。オンにした人の画面にだけ出て、
記録は本人にしか見えない。

設定の画面の「自分の設定」→「集中のしかた」で選ぶ ([設定](settings.md))。

| 項目 | 既定 | 何が変わるか |
|---|---|---|
| 今から始める (`focus.start`) | オフ | やることに「今から始める」が出る。残り時間の輪・始めた印・技の図鑑 |
| 時間の知らせ (`focus.remind`) | 終わったときだけ | 30 / 45 / 60 / 90 分ごとに、画面の隅で経った時間を知らせる (目で見るだけ) |
| 集中の音 (`focus.sound`) | オフ | 集中しているあいだ、画面の中で作った音を流せる |
| 自分の曲 (`focus.music`) | 使わない | 集中しているあいだ、自分の YouTube / SoundCloud の再生リストを流せる |
| 自分の曲のリンク (`focus.musicUrl`) | 無し | 流す再生リスト・曲のリンク |

「今から始める」がオフのあいだは、時間の知らせと集中の音・自分の曲も使わない (入口が出ない)。

## 今から始める

1. やることの一覧の行の ▶、またはやることの中の「今から始める」を押す
2. 長さを選ぶ。15 / 25 / 45 / 60 分か、好きな分 (1〜180) を書く。**決まった刻みは無い** (25分固定のポモドーロにはしない)
3. 「最初の一手」を1行だけ書ける。**書かなくても始められる**。書くとその場で「始めた」になる
   - すぐできる小さなことを1つ。「〜したら〜する」の形が始めやすい (例: 「席に戻ったら、第3条を開く」)
4. 「始める」を押すと、右下に減っていく輪と残りの分が出る。タブの題名にも「残り12分 · …」と出るので、
   文書のタブに移っても見える

楽しい演出の「済ませたらお祝い」をオンにしていると、始めたときに **LET'S GO!!**、集中したままやることを
完了にしたときに **SUPER COMPLETE!!** が出る。オフなら落ち着いた帯だけ。

### 「始めた」になる手 (カメラは使わない)

始めたかは、番頭の中で実際に手を動かしたかで確かめる。どれか1つで「始めた」の印が付く。

- 最初の一手を書いた (始めた瞬間に付く)
- そのやることにやりとりを書いた
- そのやることの中身を直した (作っただけでは数えない)
- 進捗ボードで、そのやることを作業中へ動かした (始めたあとに動かしたときだけ。始める前から作業中・完了にあったものは数えない)
- そのやることから作った改訂版に記録した

画面が「手を動かしました」と言うだけでは付かない。サーバが台帳 (やりとり・変更の履歴・記録・ボードの置き場) を
見て、本人の手が始めたあとにあるときだけ付ける。終えるときにも一度見るので、書いてからすぐ終えても取りこぼさない。
見るのは、決めた長さ (「もう少し」で延ばした分も入れる) を過ぎるまで。時間を過ぎてからの手は数えない。

最初の一手だけで「始めた」になったものも、そのあと台帳の手 (やりとり・直す・ボード・記録) を探し続ける。
**ポイントは台帳の手でだけ付く** (下の「ポイント」)。

12時間より前に始めたまま終えていないものは、置きっぱなしとみなす。確かめる・延ばす・終えるのどれを押しても
「終えないまま」で閉じ、「始めた」もポイントも付けない。

### 時間になったら

控えめな帯で3つから選ぶ。音は鳴らさない (集中の音を流していたときだけ、ゆっくり小さくして知らせる)。

- **終わった (完了にする)** — やることを完了にして、集中を「やりきった」で終える (サーバがやることの完了を
  確かめる。完了になっていなければ「やめた」として残る)
- **もう少し (+10分)** — 10分延ばす (合わせて180分まで)
- **やめる** — ここまでにする。責めない

一覧の「完了にする」から済ませても、同じく「やりきった」で終わる。別のやることを始めるには、いまの集中を終える。
終えないまま次を始めると (記録の上で)、前のものは「終えないまま次を始めた」になる。

### 集中の画面

輪の下の切り替えで、横の帯・右のペイン・知らせの数を隠す。**知らせは捨てない** (隠すだけで届いている)。
Esc で戻る。集中を終えると必ず戻る。

## 集中の音

画面の中で音を作って流す。**ファイルも外のサイトも使わない** (曲は配らない・リンクも置かない)。
自分の曲を流したいときは、下の「自分の曲を流す」。
押したときにだけ鳴り、集中を終えると止まる。番頭のタブを閉じても止まる。

| 音 | 中身 |
|---|---|
| 無音 | 既定 |
| ピンクノイズ | 高い音を抑えたノイズ |
| ブラウンノイズ | さらに低い音の多いノイズ |
| 4つ打ちビート | 拍ごとに低音の効いたキック (音程を 150Hz から 45Hz へ落とす)。裏拍のハイハットは切り替えられる。120〜150 BPM |
| ユーロビート風 | キック + 裏拍のハイハット + 裏拍で1オクターブ跳ねるベース + 2・4拍の手拍子 |

- 大きさは上限を低くしてある (上げきっても大きくならない)。始まりは4秒かけて上げる
- 1小節 (ノイズは数秒) を描いて繰り返す。背景のタブでは時計が間引かれるので、拍を時計で打たない
- 音を作れない端末では、欄の代わりに断りだけが出る
- **イヤホンで聞く前提。** スピーカーから鳴っているかは画面からは分からない
- 選んだ音・速さ・大きさは、この端末にだけ覚える

**合う人も合わない人もいる。** 一定のノイズで作業がはかどる人がいる一方で、かえって気が散る人もいる。
合わなければ止める。歌のある音楽は、読む・書く仕事の邪魔をしやすいと言われている。
番頭は効き目を約束しない。

## 自分の曲を流す

自分の YouTube か SoundCloud の再生リスト (または1曲) を、**それぞれの公式の埋め込みの再生機**で流す。
曲の権利は YouTube / SoundCloud の側で扱われる。番頭は曲を持たない。

### 設定のしかた

1. 「自分の設定」→「集中のしかた」の「自分の曲」を「自分の再生リストを流す」にする
2. 「自分の曲のリンク」にリンクを貼る。打つたびに、使えるリンクかがその下に出る
   - **YouTube**: 再生リストを開いて「共有」→「コピー」。`https://www.youtube.com/playlist?list=…` の形。
     動画1本 (`watch?v=…`・`youtu.be/…`・`shorts/…`) と YouTube Music (`music.youtube.com`) のリンクも使える。
     動画を開いたまま再生リストのリンクを写した (`watch?v=…&list=…`) ときは、再生リストのほうを流す
   - **SoundCloud**: 曲かプレイリストの「Share」→「Copy」。`https://soundcloud.com/<名前>/<曲>` か
     `https://soundcloud.com/<名前>/sets/<プレイリスト>` の形
   - 使えるのは `https://` の youtube.com (www. / m. / music.)・youtu.be・soundcloud.com だけ。ほかは断る。
     限定公開の SoundCloud のリンク (`/s-…` が付くもの) は使えない
3. 集中を始めると、残り時間の輪の下に「自分の曲」の欄が出る。**「読み込む」を押すまでは何も読み込まない**

番頭が覚えるのは、リンクの中の **id だけ** (YouTube の動画か再生リストの id、SoundCloud の名前と曲のパス)。
貼った字そのもの (`si=` などの付け足しを含む) は覚えない。流すときは id から再生機の URL を組み直す。

### 「読み込む」を押すと何が送られるか

押したときに初めて、あなたのブラウザが YouTube (`www.youtube-nocookie.com`) か SoundCloud (`w.soundcloud.com`)
につながる。そのとき相手に届くのは、ふつうにその再生機を開いたときと同じもの:

- あなたの IP アドレスとブラウザの情報、流す動画・再生リスト・曲の id
- どこから開いたか (番頭の画面の置き場所の**場所の名前だけ**。頁の中身や、やることの名前は送らない)
- YouTube は Cookie を控えめにする埋め込み (nocookie) を使う。再生を始めると、YouTube / SoundCloud の
  決まり (それぞれのプライバシーポリシー) で記録されうる

番頭からは、やることの名前・あなたのアドレス・集中の記録を送らない。押さなければ一切つながらない。

### 聞き方

- **イヤホンで聞く。** 歌の無い曲のほうが、読む・書く仕事の邪魔になりにくい
- 「止めて閉じる」で再生機ごと外す。集中を終えたときも外す
- 画面の中で作る音 (ノイズ・ビート) とは同時に流さない。片方を始めると、もう片方は止まる
- 時間になっても自分の曲は止まらない (再生機の中は番頭から操れない)。止めるときは「止めて閉じる」

### 開けないとき

職場のネットワークによっては、YouTube や SoundCloud が止められていて開けないことがある。そのときは
中の音 (ノイズ・ビート) を使う。番頭からは開けたかどうかが分からないので、断りは出ない
(再生機の枠が空のままになる)。

## 時間の知らせ

夢中になりすぎて会議や食事を飛ばさないためのもの。選んだ間隔ごとに、輪の下に「30分たちました」と
しばらく出る。目で見るだけで、音は鳴らさない。休めとは言わない。

## 集中の記録と技の図鑑 (本人だけ)

自分まわり (右上の人の印) の「集中の記録と技の図鑑」で開く。**あなたにだけ見える。続けた日数は数えない**
(途切れたときに意欲が下がるため)。

- 今週 — 始めた数・「始めた」を確かめた数・やりきった数
- 始めるまでの時間 — 「今から始める」を開いてから「始めた」になるまで。1分以内 / 5分以内 / 15分以内 / それより長く
- 技の図鑑 — 集めた技。まだのものは **???** と出る (名前も中身も見えない)

| 技 | 得るとき |
|---|---|
| 電光石火 | 開いてから1分のうちに「始めた」になった |
| 一番乗り | その日の最初の集中を、10時より前に始めた |
| やりきった | 集中しているうちに、やることを完了にした |
| 七転び八起き | 「もう少し」で延ばしたあと、最後までやりきった |
| 小さな一歩 | 最初の一手を10回書いた |
| 十回始めた | 「始めた」を10回確かめた |

技も数も台帳から数え、どこにも保存しない。やることを完全に消すと、その記録も技も消える。

## ポイント

[ポイントとレベル](home-and-game.md) がオンで、**週の上位に参加している人だけ**、確かめた始めにポイントが付く。

- **始めたあとの台帳の手 (やりとり・直す・ボードで作業中へ・記録) で確かめた始めだけ。** 最初の一手を書いただけでは
  付かない (書けば誰でも付くので。「始めた」の印と技・数にはなる)
- 1点。開いてから1分のうちに始めた、またはやることの開始日に始めたら +1 (始めるボーナス)。開いた時刻は
  サーバの時計で覚える (画面の時計は使わない。覚えていなければボーナスも電光石火も付かない)
- 同じやることには1人1日1回まで (始め直して稼げない)。**1人1日2点まで** (いくつのやることで始めても)。
  確かめていない始めには付かない

## 見えないところ

集中の記録は、使われ方・工数の集計・ホームの最近の動き・探す一覧・知らせのメールのどこにも入れない。
上長も管理者も画面からは見られない (台帳の表 `focus_sessions` には残るので、台帳を直接開ける人には読める。
ほかの表と同じ)。
