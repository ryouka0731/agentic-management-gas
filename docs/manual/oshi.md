# 推し

自分で作ったキャラクターの絵を番頭に入れると、そのキャラクターが済ませたときにほめ、ホームであいさつし、
活動に合わせて育つ。**既定はオフ**で、オンにした人の画面にだけ出る。

絵を入れる前から、**最初からいるキャラ「クロハ」** が出る (下の「最初からいるキャラ」)。

## はじめ方

1. 左の「設定」→ 自分の設定の「推し」で **推しに応援してもらう** をオンにする (`oshi.on`。[設定](settings.md))
2. 右上の自分の顔から開く欄に「推し」が出るので、押す
3. 名前と口調を決める (口調は 丁寧 / 元気 / クール / 関西弁 / 執事 / 耽美 (祈りの口調))
4. 絵を作って入れる (下の「絵の作り方」)。入れなくても、最初からいるキャラで使える

止めるときは同じ設定を外す。絵・名前・せりふをまとめて消すときは、推しの頁のいちばん下の
「推しをまとめて消す」を押す。

## 最初からいるキャラ

推しをオンにすると、自分の絵を入れる前から **クロハ** というキャラクターが出る。名前は「クロハ」、口調は
耽美 (祈りの口調。一人称は「俺」、語尾は「〜なのだ、、」) で始まる。どちらも推しの頁の「名前と口調」で変えられる。

- 絵は **2頭身** と **等身** の2つ。設定の **最初からいるキャラの絵** (`oshi.style`) で選ぶ (最初は 2頭身)
- **自分の絵を入れた表情だけ、その絵に替わる。** ほかの表情はクロハのまま
- 全部を自分のキャラにしたい・クロハを出したくないときは、設定の **最初からいるキャラを使う**
  (`oshi.useDefault`) を外す。外すと、絵の無い表情は名前の頭文字になる
- クロハの絵は見本として用意したもの。入れ物 (Drive) には置かず、番頭の中に入っている

## 絵の作り方

ChatGPT や Gemini など、画像を作れる道具を使う。番頭はその道具に何も送らない (外の API は使わない)。

1. 参考画像を1枚用意する。顔と服がはっきり見えるものが向いている
2. 画像を作る道具に参考画像を添え、推しの頁の **「最初に1回」の頼み文** を「写す」で写して貼る。
   キャラクターの特徴を書き出してもらい、表情ちがいでも同じ姿にするための頼み文である
3. 同じ会話のまま、**表情ごとの頼み文** を1つずつ写して貼り、できた絵を保存する
4. 推しの頁の表情ごとの「絵を選ぶ」から入れる

頼み文の中身は推しの頁にあり、ここには写さない (頼み文の唯一の定義は `src/core/Oshi.js`。
`test/oshi.test.js` が、この頁が頼み文を写していないかを見ている)。どの頼み文も、同じキャラクターのまま、
正方形・背景は透明か無地・上半身・文字なし・職場で困らない表現で作るよう頼んでいる。

表情は次の10枚。全部そろわなくても動く (その表情の絵が無ければ、最初からいるキャラの絵を出す。使わない設定なら
育ちの段の絵 → ふつうの絵 → 名前の頭文字の順に代える)。

| 表情 | いつ出るか |
|---|---|
| ふつう | 待っているとき・ホームのあいさつ (朝・昼) |
| ほめる | 承認した・記録した・保存した・久しぶりに開いた |
| おいわい | やることを済ませた・反映した |
| おうえん | やることを作業中にした・やることから改訂版を作った・確認を頼んだ |
| しんぱい | 押した操作が断られた (叱らない。やさしく寄り添うだけ) |
| ねむい | 夜のあいさつ |
| びっくり | 思いがけない当たり (ほめる場面の 12 回に 1 回くらい) |
| 育ち1 見習い / 育ち2 一人前 / 育ち3 名人 | 育ちの段ごとの姿 |

入れられる絵は PNG・JPEG・WebP・GIF の 1MB まで。大きい絵は送る前に画面で長い辺 512px に縮める
(GIF は動きが消えるので縮めない)。中身が名乗った形式と合わないもの (拡張子だけ変えたもの) は断る。

## 入れてよい絵

- **使ってよい絵だけ** を入れる。自分で描いた・作った絵か、使ってよいと許された絵
- **実在の人の顔は、その人の許しがあるときだけ**
- 番頭の画面では本人にだけ見せる (ほかの人の推しを読む・置く道は無い)。ただし絵と名前は入れ物の中
  (台帳の `oshi` / `oshi_images` と `objects/`) に置くので、**入れ物を Drive で共有している人は直に開ける**。
  見られて困る絵は入れない

## せりふ

せりふは口調ごとに場面ごとの決まった言葉があり、順に回して言う。場面ごとに **自分のせりふ** を足せる
(1行に1つ、10個まで・1つ60字まで)。足したせりふを先に、そのあと口調のせりふを順に言う。

場面: やることを済ませた / 反映した / 承認した / 確認を頼んだ / 記録した・保存した / 始めた / 久しぶりに開いた /
朝・昼・夜のあいさつ / うまくいかなかった / 思いがけない当たり。

吹き出しは左下に出て、6秒ほどで消える (押せば閉じる。指を乗せているあいだは消えない)。
動きを減らす設定の端末では、ふわっと出る動きを止める。音は鳴らない。

## 育てる

育ちは3段 (見習い → 一人前 → 名人)。**台帳から数え、保存しない。**

- ポイントとレベルに参加している人は、そのポイントで育つ ([ホームとポイント](home-and-game.md))
- 参加していない人は、済ませたやること (担当。担当が空なら閉じた人) と反映した確認依頼 (出した人) の数で育つ
- 10 で一人前、40 で名人。なかよしの棒は、いまの段から次の段までの進み
- 取り消しても下がらない (届いた最高の段だけを覚える)。連続日数は数えない

## ホームのカード

推しがオンのとき、ホームに推しのカードが出る。時刻 (朝 5〜11時 / 昼 11〜18時 / それ以外は夜) に合わせてあいさつし、
育ちの段となかよしの棒を出す。出したくなければ `oshi.home` (ホームであいさつする) を外す。
