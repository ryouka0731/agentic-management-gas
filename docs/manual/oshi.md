# 推し

済ませたときにキャラクターがほめ、ホームであいさつし、[実績](achievements.md) を取るたびにレベルが上がって育つ。**既定はオン**で (ほかの楽しい飾りは
既定オフだが、推しは最初から出すと決めた)、要らない人は自分の設定で止められる。どれも**自分の設定**で、チームの
設定には無い (管理者がまとめて決めることはできない)。

キャラクターは2種類ある。

- **最初からいるキャラ**: 「タク」と「イツキ」。すぐ使える (既定はタク)
- **自分のキャラ**: 自分で作った絵で、**1人 5人まで** 作れる

どれを使うかは、設定の **使うキャラ** (`oshi.char`) で、キャラの絵のカードを押して選ぶ。

## はじめ方

1. 推しは最初からオン。止めるときは、左の「設定」→ 自分の設定の「推し」で **推しに応援してもらう** を外す (`oshi.on`。[設定](settings.md))
2. 同じところの **使うキャラ** で、使うキャラのカードを押す (最初はタク)。押すと、選んだキャラがその口調で
   あいさつし、そのキャラの絵 (表情はでたらめ) が出るので、どんなキャラか分かる
3. 自分のキャラを作るときは、右上の自分の顔から開く欄の「推し」を押し、**新しいキャラを作る** を押す
4. 名前と口調を決め (口調は 丁寧 / 元気 / クール / 関西弁 / 執事 / 耽美 (祈りの口調) / 明るい相棒)、
   絵を作って入れる (下の「絵の作り方」)。**このキャラを使う** を押すか、設定の「使うキャラ」で選ぶと出る

止めるときは同じ設定を外す。自分のキャラを1人消すときは、推しの頁でそのキャラを選び、名前と口調の横の
赤いボタン (**〈名前〉 を消す**) を押す (ほかのキャラは残る)。全部をまとめて消すときは、推しの頁のいちばん下の
赤いボタン (**自分のキャラをまとめて消す**) を押す。
使っていたキャラを消すと、使うキャラは既定 (タク) に戻る。

## 最初からいるキャラ

名前・口調・絵は決まっていて、変えられない (変えたいときは自分のキャラを作る)。

| キャラ | 口調 | どんなキャラか |
|---|---|---|
| タク | 明るい相棒 | 明るくて少しおちゃめな相棒。一人称は「僕」で、です・ますに くだけた言い方が混ざる。面倒なことは道具に任せて、余白を作ろう、まず小さく試そう、と誘ってくれる |
| イツキ | 耽美 (祈りの口調) | 少し芝居がかった言い回しで、祈るように見守る。一人称は「俺」、語尾は「〜なのだ、、」 |

- 絵は **2頭身** と **等身** の2つ。設定の **最初からいるキャラの絵** (`oshi.style`) で選ぶ (最初は 2頭身)
- 絵は見本として用意したもの。入れ物 (Drive) には置かず、番頭の中に入っている
- どちらも架空のキャラクターである

## 自分のキャラ

- **1人 5人まで** 作れる。作った順に番号が付き、消した番号は次のキャラに回さない
- 名前・口調・場面ごとのせりふ・表情ごとの絵を、キャラごとに決める
- **絵を入れていない表情には、設定の「自分のキャラの絵が無い表情」(`oshi.fallback`) で選んだ最初からいるキャラ
  (タクかイツキ) の絵を出す**。「出さない」にすると、育ちの段の絵 → ふつうの絵 → 名前の頭文字の順に代える
- 育ちの段はキャラごとではなく、本人に1つ (どのキャラを使っても同じ段)

## 絵の作り方

ChatGPT や Gemini など、画像を作れる道具を使う。番頭はその道具に何も送らない (外の API は使わない)。

1. 参考画像を1枚用意する。顔と服がはっきり見えるものが向いている
2. 画像を作る道具に参考画像を添え、推しの頁の **「最初に1回」の頼み文** を「写す」で写して貼る。
   キャラクターの特徴を書き出してもらい、表情ちがいでも同じ姿にするための頼み文である
3. 同じ会話のまま、**表情ごとの頼み文** を1つずつ写して貼り、できた絵を保存する
4. 推しの頁で、絵を入れる自分のキャラを選び、表情ごとの「絵を選ぶ」から入れる

頼み文の中身は推しの頁にあり、ここには写さない (頼み文の唯一の定義は `src/core/Oshi.js`。
`test/oshi.test.js` が、この頁が頼み文を写していないかを見ている)。どの頼み文も、同じキャラクターのまま、
正方形・背景は透明か無地・上半身・文字なし・職場で困らない表現で作るよう頼んでいる。

表情は次の11枚。全部そろわなくても動く (その表情の絵が無ければ、`oshi.fallback` で選んだ最初からいるキャラの絵を出す。
「出さない」なら育ちの段の絵 → ふつうの絵 → 名前の頭文字の順に代える)。

| 表情 | いつ出るか |
|---|---|
| ふつう | 待っているとき・ホームのあいさつ (朝・昼) |
| ほめる | 承認した・記録した・保存した・久しぶりに開いた |
| おいわい | やることを済ませた・反映した |
| おうえん | やることを作業中にした・やることから改訂版を作った・確認を頼んだ |
| しんぱい | 押した操作が断られた (叱らない。やさしく寄り添うだけ) |
| ねむい | 夜のあいさつ |
| びっくり | 思いがけない当たり (ほめる場面の 12 回に 1 回くらい) |
| 育ち1 見習い / 育ち2 一人前 / 育ち3 名人 | 育ちの段ごとの姿 |
| 作業中 | 作業部屋で机に向かっているとき ([集中のしかた](focus.md) の「作業部屋」)。絵が無ければ、選んだ最初からいるキャラの作業中の絵か、ふつうの絵 |

入れられる絵は PNG・JPEG・WebP・GIF の 1MB まで。大きい絵は送る前に画面で長い辺 512px に縮める
(GIF は動きが消えるので縮めない)。中身が名乗った形式と合わないもの (拡張子だけ変えたもの) は断る。

## 入れてよい絵

- **使ってよい絵だけ** を入れる。自分で描いた・作った絵か、使ってよいと許された絵
- **実在の人の顔は、その人の許しがあるときだけ**
- 番頭の画面では本人にだけ見せる (ほかの人の推しを読む・置く道は無い)。ただし絵と名前は入れ物の中
  (台帳の `oshi` / `oshi_images` と `objects/`) に置くので、**入れ物を Drive で共有している人は直に開ける**。
  見られて困る絵は入れない

## せりふ

せりふは口調ごとに場面ごとの決まった言葉があり、順に回して言う。自分のキャラには、場面ごとに **自分のせりふ** を
足せる (1行に1つ、10個まで・1つ60字まで)。足したせりふを先に、そのあと口調のせりふを順に言う。
最初からいるキャラは、口調のせりふだけを言う。

場面: やることを済ませた / 反映した / 承認した / 確認を頼んだ / 記録した・保存した / 始めた / 久しぶりに開いた /
朝・昼・夜のあいさつ / うまくいかなかった / 思いがけない当たり / 選んでもらった / 実績を取った / 育ちの段が上がった / 実績を全部取った。

吹き出しは左下に出て、6秒ほどで消える (押せば閉じる。指を乗せているあいだは消えない)。
動きを減らす設定の端末では、ふわっと出る動きを止める。音は鳴らない。

## 育てる

育ちは3段 (見習い → 一人前 → 名人)。**レベル (Lv) は 1 + 取った[実績](achievements.md)の数** で、段は Lv で決まる。

- Lv1〜4 は見習い、Lv5 で一人前、Lv15 で名人 (段の境目は `src/core/Oshi.js` の `OSHI_STAGES()` だけが決める)
- 実績を取ると、推しが「実績を取った」のせりふでお祝いする。段が上がったときは「育ちの段が上がった」のせりふと、
  上がった段の絵 (育ち1〜3) を出す (`ach.cheer` を止めると出さない)
- **取った実績は消えないので、レベルも段も下がらない** (やることの完了を取り消しても戻らない)。連続日数は数えない
- ポイントとレベル (ホームのカード) とは別物で、ポイントでは育たない
- なかよしの棒は、いまの段から次の段までの進み

## プロフィールとクリア

推しの頁の **プロフィール** には、キャラの好きなものや口ぐせなどが並ぶ。項目ごとに「分かる Lv」が決まっていて、
**Lv が届いた項目だけ見出しと中身が出る。** まだの項目は **???** と「Lv ◯ で分かる」だけ (中身は番頭が画面に渡さない)。
Lv は実績で上がるので、設定の「実績を集める」を切っていると、頁にそう書いて Lv は上がらない (取った分は分かったまま)。
実績を取って新しく分かった項目があれば、取ったときの知らせに「推しのプロフィールが ◯ つ分かりました」と添える。

**実績を全部取ると「クリア」。** 一度クリアしたら、あとから実績が増えてもクリアのまま。 推しの頁にクリアの節が出て、プロフィールが全部分かり、キャラのお祝いの言葉が出る
(キャラに決めた言葉が無ければ、口調の「実績を全部取った」のせりふ)。お祝いの動画が決めてあれば **動画を見る** が出る。
**押すまで何も読み込まない。** 押すと YouTube の公式の埋め込みの再生機を、記録を残しにくい場所 (youtube-nocookie.com) から読み込む。
動画の場所は、クリアするまで画面に渡さない。

- **最初からいるキャラ (タク・イツキ) のプロフィールは、管理者が決める。** 設定の画面の「最初からいるキャラのプロフィール」
  (管理者だけ) か、手元からの命令 `oshiProfileSet` ([コマンドキュー](command-queue.md)) で入れる。中身は番頭の中
  (スクリプトの設定) にだけ置き、台帳にもリポジトリにも置かない。決まっていなければ「まだありません」と出る
- **自分のキャラのプロフィールは、推しの頁の「プロフィール (JSON)」で書く。** 台帳 (`oshi` の `profile`) に置くので、
  ほかの欄と同じく、入れ物を Drive で共有している人は直に開ける (お祝いの動画のリンクも)
- 書き方は JSON: `{"items": [{"lv": 2, "label": "見出し", "text": "中身"}], "clearLine": "お祝いの言葉", "clearVideo": "YouTube の動画のリンク"}`。
  項目は 40 個まで、lv は 2〜99 の整数、見出しは 20 字・中身は 200 字・お祝いの言葉は 200 字まで。
  動画は YouTube の動画1本だけ (再生リスト・ほかの場所は断る)。空にして保存すると外す。合わなければ、どこが合わないかを言って保存しない

## ホームのカード

推しがオンのとき、ホームに推しのカードが出る。時刻 (朝 5〜11時 / 昼 11〜18時 / それ以外は夜) に合わせてあいさつし、
Lv・育ちの段となかよしの棒を出す。出したくなければ `oshi.home` (ホームであいさつする) を外す。
