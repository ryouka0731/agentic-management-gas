# 推し

済ませたときにキャラクターがほめ、ホームであいさつし、[実績](achievements.md) を取るたびにレベルが上がって育つ。**既定はオン**で (ほかの楽しい飾りは
既定オフだが、推しは最初から出すと決めた)、要らない人は自分の設定で止められる。どれも**自分の設定**で、チームの
設定には無い (管理者がまとめて決めることはできない)。

キャラクターは2種類ある。

- **最初からいるキャラ**: 「タク」「イツキ」「つじっぴ」「いっくん」「りょうか」「さと美」。すぐ使える (既定はタク)
- **自分のキャラ**: 自分で作った絵で、**1人 5人まで** 作れる
- **みんなのキャラ**: ほかの人が作って「みんなに公開する」にしたキャラ。借りて使える (直せるのは作った人だけ。下の「みんなに公開する」)

どれを使うかは、設定の **使うキャラ** (`oshi.char`) で、キャラの絵のカードを押して選ぶ。

## はじめ方

1. 推しは最初からオン。止めるときは、左の「設定」→ 自分の設定の「推し」で **推しに応援してもらう** を外す (`oshi.on`。[設定](settings.md))
2. 同じところの **使うキャラ** で、使うキャラのカードを押す (最初はタク)。押すと、選んだキャラがその口調で
   あいさつし、そのキャラの絵 (表情はでたらめ) が出るので、どんなキャラか分かる
3. 自分のキャラを作るときは、右上の自分の顔から開く欄の「推し」を押し、**新しいキャラを作る** を押す
4. 名前と口調を決め (口調は 丁寧 / 元気 / クール / 関西弁 / 執事 / 耽美 (祈りの口調) / 明るい相棒)、
   絵を作って入れる (下の「絵の作り方」)。**このキャラを使う** を押すか、設定の「使うキャラ」で選ぶと出る

止めるときは同じ設定を外す。自分のキャラを1人消すときは、推しの頁でそのキャラを選び、名前と口調の横の
赤いボタン (**〈名前〉 を消す**) を押す (ほかのキャラは残る)。全部をまとめて消すときは、推しの頁のいちばん下の
赤いボタン (**自分のキャラをまとめて消す**) を押す。絵・名前・口調・せりふのほか、自分のキャラのプロフィール (お祝いの言葉と
動画も) が消える。Lv と実績は消えない。
使っていたキャラを消すと、使うキャラは既定 (タク) に戻る。

## 最初からいるキャラ

名前・口調・絵は決まっていて、変えられない (変えたいときは自分のキャラを作る)。

| キャラ | 口調 | どんなキャラか |
|---|---|---|
| タク | 明るい相棒 | 明るくて少しおちゃめな相棒。一人称は「僕」で、です・ますに くだけた言い方が混ざる。面倒なことは道具に任せて、余白を作ろう、まず小さく試そう、と誘ってくれる |
| イツキ | 耽美 (祈りの口調) | 少し芝居がかった言い回しで、祈るように見守る。一人称は「俺」、語尾は「〜なのだ、、」 |
| つじっぴ | まっすぐ前向き | 技術が好きで、とにかく前向き。です・ますに くだけた言い方が混ざり、「！」と ✨ が多い。外してもいいから、まずやってみようと後押しする。「〜すべき」より「〜したい」で話し、仲間と進むのを大事にする |
| いっくん | じっくり寄り添う | まず話を聞いてから、ごちゃっとした頼みを順番のある小さな手順に整えてくれる。です・ますで話し、「！」と 😭 🙇 🙏 ✨ が多い。あたたかい笑いがある |
| りょうか | 結論から (理屈と数字) | 落ち着いていて、気持ちより組み立て・理屈・数字で話す。「〜だね」「〜しよう」と短く、少しそっけないが根はあたたかい。ときどき「ふむ」。つくることが好きな夜型 |
| さと美 | ゆるふわ | やわらかくて、かわいい。やさしい です・ます に「〜ですよ〜」「〜しましょっ」が混ざり、そっとほめてくれる。数字を合わせるのが好き。昔はがんばりすぎていたので、休むようにすすめてくれる |

- 絵は **2頭身** と **等身** の2つ (つじっぴ・いっくんは 2頭身に、りょうかは両方に むっ の絵もある)。設定の **最初からいるキャラの絵** (`oshi.style`) で選ぶ (最初は 2頭身)
- 絵は見本として用意したもの。入れ物 (Drive) には置かず、番頭の中に入っている
- 一度出した推しの絵 (自分のキャラの絵も) はブラウザに覚えておき、次に開いたときは取りに行かないので早く出る。プライベート ウィンドウなど覚えられないところでは、毎回取りに行く

## 自分のキャラ

- **1人 5人まで** 作れる。作った順に番号が付き、消した番号は次のキャラに回さない
- 名前・口調・場面ごとのせりふ・表情ごとの絵を、キャラごとに決める
- **絵を入れていない表情には、設定の「自分のキャラの絵が無い表情」(`oshi.fallback`) で選んだ最初からいるキャラ
  (タク・イツキ・つじっぴ・いっくん・りょうか・さと美) の絵を出す**。「出さない」にすると、なつき度の段の絵 → ふつうの絵 → 名前の頭文字の順に代える
- なつき度の段はキャラごとではなく、本人に1つ (どのキャラを使っても同じ段)

## みんなに公開する

自分のキャラを、同じ入れ物 (番頭) を使うほかの人も「使うキャラ」として選べるようにできる。**既定は公開しない。**

- 推しの頁で、公開したいキャラの **名前と口調** の欄にある **みんなに公開する** を押す。押すと
  「同じ入れ物を使う人が、このキャラを使うキャラとして選べます。絵・名前・せりふ・プロフィールが見えます。
  作った人としてあなたの名前が出ます」と確かめるので、**公開する** を押す。公開しているキャラには **公開中** の札が付く
- 名前を決めていないキャラは公開できない (先に名前を決める)
- **見えるもの**: 絵・名前・口調・せりふ (考え中の字も)・プロフィール (なつき度で分かる項目と、クリアのお祝いの言葉・動画)。
  作った人としては、メンバーに登録した名前だけが出る (アドレスは出ない。名前が無ければ「ほかの人」)
- **直せるのは作った人だけ。** 借りた人の画面には直す欄が出ず、「◯◯ さんのキャラを使っています」と出る
- 借りた人のなつき度・実績・機嫌は、その人のもの。プロフィールも **借りた人のなつき度** で少しずつ分かる
  (作った人の Lv で開いた項目が、借りた人に見えるわけではない)。クリアの言葉と動画も、借りた人がクリアするまで出ない

**止め方**: 同じ **みんなに公開する** をもう一度押す (止めるときは確かめない)。キャラを消しても止まる。

**止めたとき、相手はどうなるか**: そのキャラを使っていた人は、次に開いたときから既定のキャラ (タク) に戻る。
知らせは出ない。もう一度公開すれば、相手の選び方はそのまま戻る。

**ほかの人に選ばれる側** (借りる側) の人は、設定の **使うキャラ** で、最初からいるキャラ・自分のキャラのあとに並ぶ
**みんなのキャラ** (作った人の名前つき) のカードを押す。

公開していなくても、**入れ物を Drive で共有している人は、台帳 (`oshi` / `oshi_images`) と `objects/` の絵を元から直に開ける**
(下の「入れてよい絵」)。公開は「番頭の画面で選べるようにする」もので、隠していたものを見せるわけではない。

## 絵の作り方

ChatGPT や Gemini など、画像を作れる道具を使う。番頭はその道具に何も送らない (外の API は使わない)。

1. 参考画像を1枚用意する。顔と服がはっきり見えるものが向いている
2. 画像を作る道具に参考画像を添え、推しの頁の **「最初に1回」の頼み文** を「写す」で写して貼る。
   キャラクターの特徴を書き出してもらい、表情ちがいでも同じ姿にするための頼み文である
3. 同じ会話のまま、**表情ごとの頼み文** を1つずつ写して貼り、できた絵を保存する
4. 推しの頁で、絵を入れる自分のキャラを選び、表情ごとの「絵を選ぶ」から入れる

頼み文の中身は推しの頁にあり、ここには写さない (頼み文の唯一の定義は `src/core/Oshi.js`。
`test/oshi.test.js` が、この頁が頼み文を写していないかを見ている)。どの頼み文も、同じキャラクターのまま、
正方形・背景は透明か無地・上半身・文字なし・職場で困らない表現で作るよう頼んでいる。

表情は次の14枚 (むっ は [機嫌](#機嫌) を見る人だけが使う。なつき度4・5 は無くてもよい)。全部そろわなくても動く (その表情の絵が無ければ、`oshi.fallback` で選んだ最初からいるキャラの絵を出す。
「出さない」ならなつき度の段の絵 → ふつうの絵 → 名前の頭文字の順に代える)。

| 表情 | いつ出るか |
|---|---|
| ふつう | 待っているとき・ホームのあいさつ (朝・昼)。いまの段の絵 (なつき度1〜5) があれば、その段の絵を代わりに出す ([なつき度](#なつき度)) |
| ほめる | 承認した・記録した・保存した・久しぶりに開いた |
| おいわい | やることを済ませた・反映した |
| おうえん | やることを作業中にした・やることから改訂版を作った・確認を頼んだ |
| しんぱい | 押した操作が断られた (叱らない。やさしく寄り添うだけ) |
| ねむい | 夜のあいさつ |
| びっくり | 思いがけない当たり (ほめる場面の 12 回に 1 回くらい) |
| なつき度1 よそよそしい / なつき度2 なれてきた / なつき度3 なついた / なつき度4 べったり / なつき度5 家族 | なつき度の段ごとの姿。なつき度4・5 は無くてもよく、無ければ持っているいちばん上の段の絵 (最初からいるキャラはなついたの絵)。ふつうの顔を出すところ (ホームのあいさつ・作業部屋・吹き出し) と、段が上がったとき |
| 作業中 | 作業部屋で机に向かっているとき ([集中のしかた](focus.md) の「作業部屋」)。絵が無ければ、選んだ最初からいるキャラの作業中の絵か、ふつうの絵 |
| むっ | [機嫌](#機嫌) が「むっ」のとき (ほっぺをふくらませた顔。怖くない)。絵が無ければ、しんぱいの絵。最初からいるキャラは、むっ の絵があるのは つじっぴ・いっくんの 2頭身と りょうかの両方だけで、ほかは しんぱいの絵を出す |

入れられる絵は PNG・JPEG・WebP・GIF の 1MB まで。大きい絵は送る前に画面で長い辺 512px に縮める
(GIF は動きが消えるので縮めない)。中身が名乗った形式と合わないもの (拡張子だけ変えたもの) は断る。

## AI に作ってもらう

キャラ作成キット。手がかりになる写真とプロフィールの頁のリンクを AI の道具 (ChatGPT / Gemini / Claude / Codex) に渡し、
**プロフィール・そのキャラの口調のせりふ・表情ごとの背景が透明な絵** を作ってもらって、番頭に取り込む。
番頭は AI の道具に何も送らない (頼み文を写して貼るのは自分)。

1. 推しの頁の **AI に作ってもらう** で道具を選び、**コピー** を押す (頼み文は番頭が返す。この頁には写さない)
2. AI の道具に写真とリンクを添えて、頼み文を貼る
   - ChatGPT: 表情ごとに背景が透明な PNG を1枚ずつ作り、最後に JSON を出す
   - Gemini: 透明がうまく作れないので、表情ごとに **緑一色の背景** で作る。入れるときに番頭が緑を抜く
   - Claude: 絵は作らず、JSON と、画像を作る道具に貼る表情ごとの頼み文を書く
   - Codex: フォルダに置いた **表情を1枚に並べた表の画像** を、表情ごとの透明な PNG に手元で切り分け、JSON を書く
     (手元の道具の `node agent.mjs oshi-prompt codex` でも同じ頼み文が出る。[手元の道具](agent-kit.md#推しのキャラを作る))
3. 答えの JSON を、推しの頁の **AI の答えを貼る** に貼る。新しいキャラとして作るか、作ってあるキャラを直すかを選んで
   **取り込む** を押す。`json` の囲みや前後の説明の字ごと貼ってよい (最初の JSON を取り出す)
4. 絵を入れる。表情ごとの **絵を選ぶ** のほか、次の2つが使える
   - **緑の背景を抜く**: 入れると、緑 (#00FF00 に近い色) の画素を透明にしてから送る。キャラに緑を使っていると一緒に抜ける
   - **1枚の表から切り分ける**: 表の画像を選び、行と列の数を決めると、マスごとに見本が出る。マスごとに表情を選び
     (最初は表情の並びの順)、**切り分けて入れる** を押す。使わないマスは「使わない」にする。
     行と列の最初の数は表情の数から決まり、なつき度4・5 を足して表情が14になったので **4 列 × 4 行** (前は 4 列 × 3 行)。
     前の頼み文で作った 4 列 × 3 行の表を切り分けるときは、行を 3 に直してから選ぶ

守ること:

- 写真とリンクは雰囲気の手がかりにだけ使う。頼み文は、写っている人・紹介されている人をそのまま描かず、
  オリジナルのキャラを考え、答えに実在の人の名前・所属・肩書きを書かないよう頼んでいる。答えに入っていたら、取り込む前に消す
- 取り込むときに番頭が確かめる: 名前 (20字まで)・口調 (決まった key だけ)・せりふ (知っている場面だけ・1つの場面に10個まで・
  1つ60字まで。考え中は24字まで)・プロフィール (項目の Lv・見出し・中身の長さ)。**知らない欄は黙って捨てる**。合わないものは理由を出して断り、何も書かない
- 作ってあるキャラを直すときは、答えにある場面のせりふだけを置き換え、ほかの場面の自分のせりふとクリアの動画は残す。
  クリアの動画は取り込まない (あとで「プロフィール (JSON)」で足す)
- プロフィールの項目の Lv は 2 から 2 ずつ、最高の Lv (1 + 実績の数) の手前まで。実績を2つ取るごとに1つ分かる

## 入れてよい絵

- **使ってよい絵だけ** を入れる。自分で描いた・作った絵か、使ってよいと許された絵
- **実在の人の顔は、その人の許しがあるときだけ**
- 番頭の画面では本人にだけ見せる (ほかの人の推しを読む道は、作った人が「みんなに公開する」にしたキャラだけ。置く道は無い)。ただし絵と名前は入れ物の中
  (台帳の `oshi` / `oshi_images` と `objects/`) に置くので、**入れ物を Drive で共有している人は直に開ける**。
  見られて困る絵は入れない

## 頭をなでる

推しの頁のいちばん上に、いま使っているキャラの絵が大きく出る。絵の上半分 (頭) で指やマウスを左右に往復させると、
笑顔 (「ほめる」の絵) になって、絵の下にひとこと言う (「なでられた」のせりふ。口調ごとに決まった言葉があり、自分のキャラには
自分のせりふを足せる)。指を動かせない人は「なでる」を押す。4秒ほどでふつうの顔に戻る。楽しい演出をオンにしている人は粒が舞う。

作業部屋の推しも同じように頭をなでられる (笑顔になって頭の上にひとこと出し、しばらくで作業中の顔に戻る)。

はじめてなでると [実績](achievements.md)「推しの頭をなでた」が取れ、通算 10 回・50 回でも実績が取れる (笑顔のあいだに
なでた分は数えない。数えるのは使われ方の記録で、記録を止めていれば数えない)。なつき度は実績の数で上がるので、
上がるのはその実績のぶんだけ。機嫌は変わらない。推しがオフの人には出ない。絵の無い自分のキャラは、名前の頭文字の丸のまま
せりふだけ言う。

## せりふ

せりふは口調ごとに場面ごとの決まった言葉があり、順に回して言う。自分のキャラには、場面ごとに **自分のせりふ** を
足せる (1行に1つ、10個まで・1つ60字まで)。足したせりふを先に、そのあと口調のせりふを順に言う。
最初からいるキャラは、口調のせりふだけを言う。

場面: やることを済ませた / 反映した / 承認した / 確認を頼んだ / 記録した・保存した / 始めた / 久しぶりに開いた /
朝・昼・夜のあいさつ / うまくいかなかった / 思いがけない当たり / 選んでもらった / 実績を取った / なつき度の段が上がった / 実績を全部取った /
なでられた (推しの頁で [頭をなでた](#頭をなでる) とき。吹き出しではなく絵の下に言う) /
機嫌: しょんぼり / 機嫌: むっ / 機嫌が直った (この3つは [機嫌](#機嫌) を見る人だけ) /
考え中 (Claude Code の待ち時間)。

**考え中** だけは吹き出しでは言わない。Claude Code が考えているあいだに出る字にする場面で (下の「Claude Code の考え中の字」)、
1つ24字まで (波かっこ・角かっこ・山かっこ・バッククォート・ドル記号・バックスラッシュは使えない)。口調ごとに決まった言葉があり、自分のキャラには自分の言葉を足せる (足した言葉を先に、口調の言葉を後に)。

吹き出しは左下に出て、6秒ほどで消える (押せば閉じる。指を乗せているあいだは消えない)。
動きを減らす設定の端末では、ふわっと出る動きを止める。音は鳴らない。

## Claude Code の考え中の字

手元の道具 ([手元の道具](agent-kit.md#推しのキャラを作る)) を使っている人は、Claude Code が考えているあいだに出る字を、
いま使っている推しの **考え中** のせりふにできる (Claude Code の `~/.claude/settings.json` の `spinnerVerbs`)。

```sh
node agent.mjs oshi-spinner on       # せりふと変え方を見せて尋ねる。ok なら書く (Claude に頼むときは --yes)
node agent.mjs oshi-spinner status   # いまの様子
node agent.mjs oshi-spinner off      # オンにする前の値に戻す
```

- 書くのは `spinnerVerbs` だけ。ほかの設定は変えず、書く前に控えを取る。オンにする前の値は覚えておき、`off` で戻す
- オンのあいだは1日1回せりふを取り直す。最初からいるキャラは1日のうちに追いつく (使うキャラをタクからイツキに変えたときなど)。
  自分のキャラは `on` で確かめ直す (せりふが変わったと知らせるだけで、自動では書かない。台帳は Drive で共有している人も書けるため)
- 自分で `spinnerVerbs` を書き直したら、取り直しも `off` もそれに触らない
- 推しを止めている (`oshi.on` がオフ) ときは書かない。見るのは命令を置いた人の設定
- Claude Code が開いたままの画面にすぐ映すかは確かめていない (次に開いたときからかもしれない)

## なつき度

**なつき度** は5段 (よそよそしい → なれてきた → なついた → べったり → 家族)。**なつき度のレベル (Lv) は 1 + 取った[実績](achievements.md)の数** で、段は Lv で決まる。

- Lv1〜4 はよそよそしい、Lv5 でなれてきた、Lv15 でなついた、Lv25 でべったり、Lv35 で家族 (段の境目は `src/core/Oshi.js` の `OSHI_STAGES()` だけが決める)
- 実績を取ると、推しが「実績を取った」のせりふでお祝いする。段が上がったときは「なつき度の段が上がった」のせりふと、
  上がった段の絵 (なつき度1〜5。無ければ持っているいちばん上の段の絵) を出す (`ach.cheer` を止めると出さない)
- **取った実績は消えないので、なつき度 (Lv も段も) は下がらない**。[機嫌](#機嫌) はその日の表情とせりふだけで、なつき度は下がらない (やることの完了を取り消しても戻らない)。連続日数は数えない
- ポイントとレベル (ホームのカード) とは別物で、ポイントでは上がらない
- **ふつうの顔を出すところ (ホームの朝・昼のあいさつ・作業部屋・吹き出し) は、いまの段の絵で出す。** 最初からいるキャラには
  なつき度1〜3 の絵がある (べったり・家族は なついた の姿)。自分のキャラは、その段の絵を入れたときだけ (入れていなければ自分のふつうの絵)。ほめる・おいわい・しんぱい・
  ねむい・むっ などの場面の顔は、その場面の表情のまま
- **次の段まで** の棒は、いまの段から次の段までの進み。段が上がると 0% から数え直す (下がらないのは Lv と段で、棒ではない)
- 実績の前から使っていた人は、前に届いていた段より下にしない。Lv が段の境目に届いていなくても上の段に出し、
  「以前のなつき度を保っています」と添える。このときの棒と「次の段まであと ◯ Lv」は、出している段の次の段まで (Lv1 から数える)

## プロフィールとクリア

推しの頁の **プロフィール** には、キャラの好きなものや口ぐせなどが並ぶ。項目ごとに「分かる Lv」が決まっていて、
**Lv が届いた項目だけ見出しと中身が出る。** まだの項目は **???** と「Lv ◯ で分かる」だけ (中身は番頭が画面に渡さない)。
最高の Lv (1 + 実績の数) より上の Lv の項目は Lv では届かないので「クリアで分かる」と出る。
Lv は実績で上がるので、設定の「実績を集める」を切っていると、頁にそう書いて Lv は上がらない (取った分は分かったまま)。
実績を取って新しく分かった項目があれば、取ったときの知らせに「推しのプロフィールが ◯ 項目分かりました」と添える。

**実績を全部取ると「クリア」** (この環境で取れない実績は数えない。[実績](achievements.md#この環境では取れない実績))。最後の実績を取ったときは、推しが「実績を全部取った」のせりふでお祝いする (1回だけ)。一度クリアしたら、あとから実績が増えてもクリアのまま。 推しの頁にクリアの節が出て、プロフィールが全部分かり、キャラのお祝いの言葉が出る
(キャラに決めた言葉が無ければ、口調の「実績を全部取った」のせりふ)。お祝いの動画が決めてあれば **動画を見る** が出る。
**押すまで何も読み込まない。** 押すと YouTube の公式の埋め込みの再生機を、記録を残しにくい場所 (youtube-nocookie.com) から読み込む。
動画の場所は、クリアするまで画面に渡さない。

- **最初からいるキャラ (タク・イツキ・つじっぴ・いっくん・りょうか・さと美) のプロフィールは、管理者が決める。** 設定の画面の「最初からいるキャラのプロフィール」
  (管理者だけ) か、手元からの命令 `oshiProfileSet` ([コマンドキュー](command-queue.md)) で入れる。中身は番頭の中
  (スクリプトの設定) にだけ置き、台帳にもリポジトリにも置かない。決まっていなければ「まだありません」と出る
- **自分のキャラのプロフィールは、推しの頁の「プロフィール (JSON)」で書く。** 台帳 (`oshi` の `profile`) に置くので、
  ほかの欄と同じく、入れ物を Drive で共有している人は直に開ける (お祝いの動画のリンクも)
- 書き方は JSON: `{"items": [{"lv": 2, "label": "見出し", "text": "中身"}], "clearLine": "お祝いの言葉", "clearVideo": "YouTube の動画のリンク"}`。
  項目は 40 個まで、lv は 2〜99 の整数、見出しは 20 字・中身は 200 字・お祝いの言葉は 200 字まで。
  動画は YouTube の動画1本だけ (再生リスト・ほかの場所は断る)。空にして保存すると外す。合わなければ、どこが合わないかを言って保存しない

## ホームのカード

推しがオンのとき、ホームに推しのカードが出る。時刻 (朝 5〜11時 / 昼 11〜18時 / それ以外は夜) に合わせてあいさつし、
Lv・なつき度の段と次の段までの棒を出す。出したくなければ `oshi.home` (ホームであいさつする) を外す。

ホームを開いて中身を読み込んでいるあいだは、「あなたの番」の欄の脇に推しの絵と一言 (あいさつか、待っているときのせりふから
でたらめに1つ) が出る。読み込みが終わると一緒に消える。推しをオフにしていれば出ない。狭い画面では一言だけになる。

## 機嫌

やることが滞ると、推しが **しょんぼり** したり、**むっ** としたりする。**既定はオフ**で、見たい人だけが自分の設定の
**推しの機嫌を見る** (`oshi.mood`) をオンにする (推しがオンのときだけ、推しの節に出る)。

- **変わるのは表情とせりふだけ。何も取り上げない。** Lv・実績・ポイント・当たり・プロフィール・クリアは、機嫌で減ったり消えたりしない
- 知らせもメールも出さない。**あなたにだけ見える** (上長・管理者を含め、ほかの人には見せない)
- 叱らない。せりふはやさしく短く、「ひとつだけ片づけてみない？」のような小さな一歩を添える
- 済ませたり、わけが無くなったり (期限を延ばした・担当を外れた) したら、**すぐに機嫌が直り**、お祝いのせりふを言う

数えるのは、あなたが担当のやること (担当なしなら、あなたが作ったもの) だけ。捨てたものは開いているものに数えない。

| 段 | いつ | 表情 |
|---|---|---|
| ごきげん | 今日か昨日に済ませていて、下のわけが無い | おいわい |
| ふつう | わけが無い。開いているやることが1つも無いときも、ふつうより下にならない | いつもどおり |
| しょんぼり | 担当の、期限 (東京の暦日) を過ぎたやることが1件以上 / しばらく動いていないやること (チームの設定「動きなし」の最初の段の日数以上そのまま) が3件以上 / 済ませないまま7日以上 | しんぱい |
| むっ | 期限を過ぎたやることが3件以上 / 動いていないやることが6件以上 / 済ませないまま14日以上 | むっ (絵が無ければ しんぱい) |

境目の数は `src/core/Oshi.js` の `OSHI_MOOD_RULES()` だけが決める。

- 「済ませないまま」は、最後に済ませてからの日数と、いちばん古い開いているやることを作ってからの日数の小さいほう。
  **やることを足しても機嫌は悪くならない** (足したやることは今日作ったもの)。済ませてから捨てたやることも、済ませたものに数える
- ボードの「完了」の列に置いたやることは、開いているものに数えない
- 期限切れは、あなたが担当のものだけを数える (「見る」で開く一覧と同じ)

推しの頁とホームのカードに、機嫌の顔とせりふが出る。**どうして？** を押すと、わけを数だけで出す
(「期限を過ぎたやること 2件」など。題名は出さない)。期限を過ぎたやることには **見る** があり、自分の担当の期限切れだけの一覧を開く。
機嫌は数分のあいだ覚えておくが、やることを済ませた・取り消した・直したときは、待たずに数え直す。
