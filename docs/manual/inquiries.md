# 要望・不具合

[手引きの目次](README.md)

左の「要望・不具合」は、使っていて困ったことをその場から送れる相談板。口頭やメールで伝えられた報告は集まらないまま
消えるので、台帳 (`inquiries`) に貯めて、誰が何につまずいたかを残す。実装は `src/core/Inquiry.gs`。

## 送る

「開発者に伝える」から、種類を選んで書く。

| 種類 | 積まれるやることのタグ |
|---|---|
| うまく動かない | 不具合 |
| こうしてほしい (機能の要望) | 要望 |
| 使い方が分からない | 問合せ対応 |
| その他 | — |

- 見ている画面と使っている環境も一緒に届く
- 画像を4枚まで添えられる (PNG / JPEG / GIF / WebP、1枚5MBまで)。入れ物の `.git/shots/` に置かれる
- 送った人はサーバ側で決める (画面から名乗りを受け取ると詐称できるため)

## 届くところ

- 送られたものは、**このアプリの持ち主のやること**に自動で積まれ、進捗ボードの「これから」に並ぶ。持ち主が
  分からないとき・複数いるとき (共有ドライブ) は担当なしで積む
- 持ち主全員に知らせが届く (メールの種類「報告とその返事」)
- 報告を解決すると、積まれたやることも完了になる。開き直すと、やることも開き直る

## 読む・返す

- 報告は**みんなが読めて、誰でも返信できる**。同じことで困った人が先に答えを知っていることがある
- 返信の中で `@名前` と書くと、その人に知らせが届く。`@` を打つと候補が出る。名簿に無い名前は誰にも届かない
- 自分の返信は書き直し・消しができる
- 返信は、報告を出した人とそれまでに返信した人に知らせる
- 上の欄で内容・種類・書いた人で絞れる。「未解決だけ」で開いているものに絞る

## 閉じる

**「解決した」を押せるのは、出した本人と管理者だけ。** 同じ人が開き直せる。

## 改善のヒントとのつながり

「使い方が分からない」が30日で3件以上あると、管理者のホームに「使い方の問い合わせが続いています」のヒントが出る
([ホームとポイント](home-and-game.md#改善のヒント))。件数だけで、誰が出したかは言わない。
