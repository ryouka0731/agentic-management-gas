# 使い方の手引き

SoftBanto（そふと番頭、通称 番頭）を置く人・使う人・手元から動かす人・開発する人のための手引き。
画面の中の「使い方」(左の「困ったとき」) は使う人向けの短い説明で、ここはその詳しい版にあたる。

コードと食い違ったときはコードが正しい。食い違いに気づいたら、この手引きを直す。
`test/docs.test.js` が、命令の一覧と設定の一覧とリンク切れだけは機械的に見ている。

## 言葉

| 画面の言葉 | Git でいうと |
|---|---|
| 正式版 | main |
| 改訂版 | ブランチ |
| 変更の記録 | コミット |
| 確認依頼 | プルリクエスト |
| 反映 | マージ |
| やること | Issue |
| 進捗ボード | Projects |

ほかに画面で使う言葉:

- **やりとり** — やることや確認依頼の中で話し合った跡
- **下書き** — やることの補足に差し込む、よく使う形 (ひな形)
- **タグ** — どんな種類の仕事かの印。`#` で書く
- **管理者** — このアプリの持ち主と、入れ物のフォルダを編集できる人 ([管理](admin.md))
- **台帳** — 入れ物の `.git/` の中にある `agentic-management repo-db` スプレッドシート。番頭のデータはすべてここにある
- **入れ物** — Drive の `agentic-management/` フォルダ。名前だけは改名前のまま残してある
