# 仕事のスタンス診断

20問に答えると、仕事の進め方の型 (16のどれか) が分かる。型に合った番頭の使い方のおすすめが出て、手元の Claude も
手伝い方を合わせる。**遊びの診断で、人の評価や配置には使わない。医学的・心理学的な検査でもない。**
問いも型の名前もこの道具のために書いたもので、ほかの性格検査の型や記号は使っていない。

## 開き方

上の帯の自分の顔 →「仕事のスタンス診断」。右のパネルに20問が出る。答えは「そう思わない」「あまり思わない」
「どちらとも言えない」「ややそう思う」「そう思う」の5段。全部答えると「結果を見る」が押せる。何度でもやり直せる。

## 4つの軸と16の型

| 軸 | 左の極 | 右の極 |
|---|---|---|
| 始め方 | すぐ動く | 段取りから |
| 進め方 | ひとりで集中 | 声をかけ合う |
| 力が出る時 | 締切が近いと | コツコツ毎日 |
| 惹かれるもの | 新しいこと | 決まった型を磨く |

| 始め方・進め方 | 締切が近いと・新しいこと | 締切が近いと・決まった型 | コツコツ・新しいこと | コツコツ・決まった型 |
|---|---|---|---|---|
| すぐ動く・ひとり | 🚀 一番乗りの開拓者 | 🔨 追い込みの職人 | 🧭 気ままな探検家 | 🪵 黙々の名工 |
| すぐ動く・声かけ | 🎆 お祭りの火付け役 | ⚡ 現場の切り込み隊長 | 🚩 好奇心の旗振り役 | 🤝 頼れる世話焼き番 |
| 段取り・ひとり | 💡 計算ずくの発明家 | 🎯 土壇場の仕上げ人 | 🔬 静かな研究者 | 📐 段取りの匠 |
| 段取り・声かけ | ♟️ 作戦会議の軍師 | 🗓️ 締切の司令塔 | 🧩 仕組みの設計士 | 🌱 みんなの縁の下 |

## 数え方

- 軸ごとに5問。1問ごとに (答え − 3) を、その問いの向きで左か右の極に足す (−10〜+10)
- 向きは軸ごとに両方を2問以上混ぜ、全体で左向き・右向きを10問ずつにしてある。「そう思う」と答え続ける癖だけで型が決まらない
- 合計が正なら左、負なら右。**ちょうど 0 のときは左の極**にし、画面に「どちらとも言えない」と添える
- 同じ答えなら、いつ数えても同じ型になる。定義は `src/core/WorkStyleTypes.js` の1か所だけ (画面は受け取って描く)

## 結果に出るもの

- 型の名前・絵・ひとこと・強み・気をつけたいこと
- 軸ごとの寄り方 (はっきり / やや / どちらとも言えない) と、極ごとのひとこと
- **番頭の使い方のおすすめ** — その型に合いそうな、今ある機能 (ホームのカード・楽しい演出・通知メール・進捗ボード・工程表など)。
  設定は「設定で見る」でその項目を開いて印を付けるだけで、**切り替えはしない** (オンにするかは本人が決める)

## 誰に見えるか

| もの | 見える人 |
|---|---|
| 点数・答え・診断した日 | 本人だけ (持ち主はエディタのスクリプトプロパティで見られる) |
| 型の名前と絵 | 本人。自分の設定 `style.share` (「型の名前をチームに見せる」) をオンにしたときだけ、ほかの人の画面の顔の読み上げ・吹き出しにも添える |

- 既定はオフ。結果の画面の切り替えか、設定の「自分の設定」で切り替える
- 「結果を消す」で結果を消すと、見せる設定も既定 (見せない) に戻る
- 結果は台帳ではなくスクリプトプロパティ `STYLE:<小文字のアドレス>` に置く (台帳は Drive を共有している人なら誰でも読めるため)

## 社内チャットに共有する

- **共有用の札をコピー** — 型の名前・ひとこと・強み・軸を字の札にして写す。Google Chat や Slack にそのまま貼れる。点数は入らない
- **画像で保存** — 同じ札を画像 (PNG) に描く。保存を断られる環境でも画像はその場に出るので、右クリックや長押しで保存できる
- 番頭からチャットへは何も送らない (外の API は使わない決まり)

## 手元の Claude

```sh
node agent.mjs style
```

型と、軸ごとの手伝い方の合わせ方が返る (点数は返さない)。配った道具の中のスキル `banto-style` が、それを読んで手伝い方を
合わせる (すぐ動く型には最初の一歩から、段取り型には短い段取りから、ひとり集中型には質問をまとめて、締切型には小さな
区切りを、など)。型は目安で、本人の頼み方が先。返事は命令の入れ先に置かれるので、入れ先を共有している人なら読める
(ほかの「自分の様子を見る」命令と同じ)。命令の形は [コマンドキュー](command-queue.md) と [手元の道具](agent-kit.md)。
