# やることを気持ちよく片づける (段階①) 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** やることを完了にした瞬間に「何が起きたか」を1つだけ返し、ホームに今日片づけたものを出し、既定オフのポイント・レベル・週の上位3人を足す。

**Architecture:** 数はすべて台帳 (`issues` / `reviews` / `pulls` / `change_log`) からその場で数え、どこにも保存しない (レベルの最高だけ UserProperties に覚える)。サーバの判定は `src/core/Motivation.gs` (知らせ・今日) と新しい `src/core/Game.gs` (ポイント・レベル・上位) に置き、`src/Main.gs` の `api*` が開いている本人のアドレスだけを渡す。画面は `src/ui/app.js.html` の `celebrateProgress` とホームのカードを広げる。

**Tech Stack:** Google Apps Script (V8)、vitest + `test/fakegas.js` の疑似GAS、jsdom (`test/dom.js`)。

**Spec:** `docs/superpowers/specs/2026-10-14-task-flow-motivation-design.md`

## Global Constraints

- ランタイムコードに `import` / `export` / `require` を書かない (GAS で動かない)
- 画面へ返す値は `src/core/Plain.js` の `plainText` / `plainNumber` / `plainId` / `plainDate` だけを通す。Date を返さない
- アドレスを受ける関数は末尾 `_` にする (画面から直に呼べない)。`api*` は `Session.getActiveUser().getEmail()` だけを渡す
- 台帳は表ごとに1回だけ読む。行ごとに `dbFindOne` をしない
- 鍵は `dbWithLock_` 以外で取らない
- UI は `textContent` のみ。`innerHTML` を使わない
- サーバ呼び出しは `call()` だけ。`google.script.run` を直に書かない
- CSS は既存トークンのみ (`--ink` / `--ink-2` / `--line` / `--bg` / `--bg-2` / `--accent` / `--success`)。`var(--x, fallback)` を書かない
- 東京の暦日は `motivationDay_` で求める
- 定数: `CLOSE_LONG_DAYS() = 14`、`CLOSE_HEAVY_POINTS() = 5`、`CLOSE_HEAVY_HOURS() = 4`
- レベル n に必要な合計: `5 × n × (n + 1) / 2`
- ゲームは `GAME_ENABLED === 'true'` のときだけ。既定オフ。参加者は `GAME_PLAYERS` (JSON 配列)、既定は不参加
- 週の上位は上位3位まで。上位にいない人に自分の順位を返さない
- 「人事の評価には使いません」を順位とレベルのカードに書く
- 演出は印1つ・300ms。`prefers-reduced-motion: reduce` では動かさない。紙吹雪・音を入れない
- 新しい `api*` は `test/phase4-edit.test.js` の「画面に渡せる形か」と `test/dom.js` の呼べる名前・`DEFAULTS` に足す (`DEFAULTS` に同じキーを二度書かない)

## Review Focus

1. **担当が空で、閉じた記録も無いやること** (変更の履歴を足す前に閉じたもの) — 今日の一覧にもポイントにも載らず、例外も出さない。Task 2・3 にテストを置く
2. **子が全部捨てられた親** — `total === 0` のとき `parentDone` / `parentStep` にしない (0/0 を「全部終わった」と読まない)。Task 1 にテストを置く
3. **台帳から Date で返る日付と、字の日付が混ざる** — `points` / `plannedHours` が空字・字の数でも判定できる。Task 1 にテストを置く
4. **`GAME_PLAYERS` が手で壊された** (JSON でない) — 空の参加者として読み、例外にしない。Task 3 にテストを置く
5. **知らせを止めた直後に `apiCloseFeedback` の返事が届く** — 素の帯のまま、ポイントもレベルも出さない。Task 5 にテストを置く

```js
/**
 * 作ってからこの日数以上たって片づいたものを「長く止まっていたもの」とする。
 * 入れたあと4週で見直す。
 *
 * @returns {number}
 */
function CLOSE_LONG_DAYS() {
  return 14;
}

/** @returns {number} これ以上のポイントを「重いもの」とする */
function CLOSE_HEAVY_POINTS() {
  return 5;
}

/** @returns {number} これ以上の予定時間を「重いもの」とする */
function CLOSE_HEAVY_HOURS() {
  return 4;
}

/**
 * ミリ秒。読めなければ NaN。台帳からは Date でも字でも返ってくる。
 *
 * @param {*} v
 * @returns {number}
 */
function motivationTime_(v) {
  if (!v) return NaN;
  if (Object.prototype.toString.call(v) === '[object Date]') return v.getTime();
  return Date.parse(String(v));
}

/**
 * 重いものか。件数だけをほめると簡単なものから手を付けるようになる (KC ら 2020)
 * ので、重さにも同じ手応えを返す。
 *
 * @param {object} row issues の行
 * @returns {boolean}
 */
function motivationIsHeavy_(row) {
  var p = Number(row.points);
  var h = Number(row.plannedHours);
  return (isFinite(p) && p >= CLOSE_HEAVY_POINTS()) || (isFinite(h) && h >= CLOSE_HEAVY_HOURS());
}

/**
 * 作ってから閉じるまでの日数 (東京の暦日で数える)。読めなければ 0。
 *
 * @param {object} row issues の行
 * @returns {number}
 */
function motivationWaitedDays_(row) {
  var from = motivationDay_(row.createdAt);
  var to = motivationDay_(row.closedAt);
  if (!from || !to) return 0;
  return Math.round((Date.parse(to + 'T00:00:00Z') - Date.parse(from + 'T00:00:00Z')) / 86400000);
}

/**
 * 親ごとの子。**捨てた子は入れない。** 残りとして居座ると親が永遠に終わらない。
 *
 * @param {object[]} issues
 * @returns {Object<string, object[]>}
 */
function motivationChildren_(issues) {
  var kids = {};
  for (var i = 0; i < issues.length; i++) {
    var p = issues[i].parent;
    if (!p || issues[i].archivedAt) continue;
    var key = String(p);
    (kids[key] = kids[key] || []).push(issues[i]);
  }
  return kids;
}

/**
 * 完了にしたやることについて、何が起きたかを**1つだけ**選んで返す。
 * 重ねると派手になり、どれも残らない。
 *
 * くじで驚かせず、本当に起きたことで驚かせる。ドーパミンは予想との差に反応する
 * (Schultz ら 1997) が、確率で変わる報酬は職場ではギャンブルと同じ形になる。
 *
 * @param {number} number
 * @param {Date} now
 * @returns {object}
 */
function closeFeedback_(number, now) {
  var issues = dbReadAll('issues');
  var byNo = {};
  for (var i = 0; i < issues.length; i++) byNo[String(issues[i].number)] = issues[i];

  var row = byNo[String(number)];
  if (!row) throw new Error('やること #' + number + ' が見つかりません');

  var team = motivationProgress(now);
  var out = {
    kind: 'team',
    number: Number(row.number),
    title: String(row.title || ''),
    weekClosed: team.weekClosed,
    monthClosed: team.monthClosed,
    goal: team.goal,
  };

  var parent = row.parent ? byNo[String(row.parent)] : null;
  if (parent && String(parent.state) !== 'closed' && !parent.archivedAt) {
    var kids = motivationChildren_(issues)[String(parent.number)] || [];
    var done = 0;
    for (var k = 0; k < kids.length; k++) if (String(kids[k].state) === 'closed') done++;
    // 子が全部捨てられていると 0/0 になる。それを「全部終わった」と読まない
    if (kids.length) {
      out.parent = { number: Number(parent.number), title: String(parent.title || ''),
        done: done, total: kids.length };
      out.kind = done === kids.length ? 'parentDone' : 'parentStep';
      return out;
    }
  }

  var days = motivationWaitedDays_(row);
  if (days >= CLOSE_LONG_DAYS()) {
    out.kind = 'longAwaited';
    out.days = days;
    return out;
  }
  if (motivationIsHeavy_(row)) out.kind = 'heavy';
  return out;
}
```

```js
/**
 * 完了にしたやることについて、何が起きたかを1つ返す (Web App API)。
 *
 * @param {number} number
 * @returns {object}
 */
function apiCloseFeedback(number) {
  var fb = closeFeedback_(Number(number), new Date());
  var out = {
    kind: plainText(fb.kind),
    number: plainId(fb.number),
    title: plainText(fb.title),
    weekClosed: plainNumber(fb.weekClosed),
    monthClosed: plainNumber(fb.monthClosed),
    goal: plainNumber(fb.goal),
  };
  if (fb.parent) {
    out.parent = { number: plainId(fb.parent.number), title: plainText(fb.parent.title),
      done: plainNumber(fb.parent.done), total: plainNumber(fb.parent.total) };
  }
  if (fb.days) out.days = plainNumber(fb.days);
  return out;
}
```

```js
/**
 * やることごとに、最後に閉じた人。担当が空のやることを誰のものとして数えるかに使う。
 *
 * @returns {Object<string, string>} 番号の字 → アドレス
 */
function motivationClosers_() {
  var rows = dbReadAll('change_log');
  var out = {};
  // 足した順に並んでいるので、後の行が勝つ
  for (var i = 0; i < rows.length; i++) {
    if (String(rows[i].action) !== 'close') continue;
    var m = /^issue:(\d+)$/.exec(String(rows[i].target || ''));
    if (m && rows[i].actor) out[m[1]] = String(rows[i].actor);
  }
  return out;
}

/**
 * このやることを誰のものとして数えるか。担当がいれば担当、空なら閉じた人。
 *
 * @param {object} row
 * @param {Object<string, string>} closers motivationClosers_()
 * @returns {string[]}
 */
function motivationCredited_(row, closers) {
  var who = issueAssignees(row);
  if (who.length) return who;
  var c = closers[String(row.number)];
  return c ? [c] : [];
}

/**
 * 今日片づけたもの。**本人にだけ**見せる。
 *
 * **画面から直に呼べない名前にする (末尾 _)。** アドレスを受けるので、呼べると
 * ほかの人の一日を覗ける。apiMyToday が開いている本人のアドレスだけを渡す。
 *
 * @param {string} email
 * @param {Date} now
 * @returns {Array<{kind: string, number: number, title: string}>}
 */
function myToday_(email, now) {
  var me = String(email || '');
  var today = motivationDay_(now);
  var out = [];
  if (!me || !today) return out;

  var closers = motivationClosers_();
  var issues = dbReadAll('issues');
  for (var i = 0; i < issues.length; i++) {
    var row = issues[i];
    if (String(row.state) !== 'closed' || motivationDay_(row.closedAt) !== today) continue;
    if (motivationCredited_(row, closers).indexOf(me) < 0) continue;
    out.push({ kind: 'issue', number: Number(row.number), title: String(row.title || '') });
  }

  var pulls = dbReadAll('pulls');
  for (var p = 0; p < pulls.length; p++) {
    var pr = pulls[p];
```

```js
/**
 * ポイント・レベル・週の上位。
 *
 * 第1段階では入れないと決めていたが、利用者の判断で入れた
 * (docs/superpowers/specs/2026-10-14-task-flow-motivation-design.md)。文献の害が
 * 消えるわけではないので、次の守りを付けている。崩さないこと。
 *
 * - **件数ではなく重さで付ける。** 件数だけだと簡単なものから手を付ける (KC ら 2020)
 * - **上位3人だけ出す。** 職場の順位の下位は晒しになる (Jia ら 2017)
 * - **週ごとに数え直す。** 通算だと古参が居座る
 * - **既定オフ・参加は本人が選ぶ。** 監視に見えるとストレスが増える (Ravid ら 2023)
 * - **数は台帳から数え、保存しない。** 手で書く数は必ずずれる。取り消せば消える
 */

/** @returns {string} */
function GAME_ENABLED_KEY() {
  return 'GAME_ENABLED';
}

/** @returns {string} 参加者のアドレスの JSON 配列を置く鍵 */
function GAME_PLAYERS_KEY() {
  return 'GAME_PLAYERS';
}

/** @returns {boolean} */
function gameEnabled() {
  return PropertiesService.getScriptProperties().getProperty(GAME_ENABLED_KEY()) === 'true';
}

/**
 * 切り替える。管理者かどうかは呼ぶ側で確かめる。オフにしても参加者は消さない。
 *
 * @param {boolean} on
 * @returns {boolean}
 */
function gameSetEnabled_(on) {
  var props = PropertiesService.getScriptProperties();
  if (on) props.setProperty(GAME_ENABLED_KEY(), 'true');
  else props.deleteProperty(GAME_ENABLED_KEY());
  return gameEnabled();
}

/**
 * 順位に参加している人。手で壊されていても空として読む。
 *
 * @returns {string[]}
 */
function gamePlayers() {
  var raw = PropertiesService.getScriptProperties().getProperty(GAME_PLAYERS_KEY());
  if (!raw) return [];
  try {
    var list = JSON.parse(raw);
    return Array.isArray(list) ? list.filter(function (x) { return typeof x === 'string' && x; }) : [];
  } catch (e) {
    return [];
  }
}

/**
 * 参加する・やめる。**読む → 足す/外す → 書くを1つの鍵の中で行う。**
 * 分けると、ほぼ同時に押した2人のどちらかが消える。
 *
 * @param {string} email
 * @param {boolean} on
 * @returns {boolean} 切り替えたあと参加しているか
 */
function gameSetPlaying_(email, on) {
  var me = String(email || '');
  if (!me) throw new Error('誰か分かりません');
  return dbWithLock_(30000, function () {
    var list = gamePlayers().filter(function (x) { return x !== me; });
    if (on) list.push(me);
    PropertiesService.getScriptProperties().setProperty(GAME_PLAYERS_KEY(), JSON.stringify(list));
    return list.indexOf(me) >= 0;
  });
}

/**
 * レベル n に必要な合計。上がるほど遠くなる。
 *
 * @param {number} n
 * @returns {number}
 */
function gameLevelAt(n) {
  return 5 * n * (n + 1) / 2;
}

/**
 * 合計からレベルを決める (0 から)。
 *
 * @param {number} total
 * @returns {number}
 */
function gameLevel(total) {
  var n = 0;
  while (gameLevelAt(n + 1) <= total) n++;
  return n;
}

/**
 * このやること全体のポイント (頭数で割る前)。
 *
 * @param {object} row 閉じたやること
 * @param {Object<string, object[]>} kids motivationChildren_()
 * @returns {number}
 */
function gameIssuePoints_(row, kids) {
  var n = 1;
  if (motivationIsHeavy_(row)) n += 2;
  if (motivationWaitedDays_(row) >= CLOSE_LONG_DAYS()) n += 2;

  // 小分けの最後の1つ。いまの子の状態で見る (後で子が開き直されたら消える)
  var sibs = row.parent ? (kids[String(row.parent)] || []) : [];
  if (sibs.length && !row.archivedAt) {
    var last = null;
    for (var i = 0; i < sibs.length; i++) {
      if (String(sibs[i].state) !== 'closed') { last = null; break; }
      if (!last || motivationTime_(sibs[i].closedAt) > motivationTime_(last.closedAt)) last = sibs[i];
    }
    if (last && String(last.number) === String(row.number)) n += 1;
  }
  return n;
}

/**
 * 人ごとのポイント。台帳を表ごとに1回だけ読む。
 *
 * @param {string} from 'YYYY-MM-DD' ('' なら端なし)
 * @param {string} to 'YYYY-MM-DD' ('' なら端なし)
 * @returns {Object<string, number>}
 */
function gamePointsByPerson_(from, to) {
  var pts = {};
  function inSpan(day) { return !!day && (!from || day >= from) && (!to || day <= to); }
  function add(who, n) { if (who) pts[who] = (pts[who] || 0) + n; }

  var issues = dbReadAll('issues');
  var kids = motivationChildren_(issues);
  var closers = motivationClosers_();
  for (var i = 0; i < issues.length; i++) {
    var row = issues[i];
    if (String(row.state) !== 'closed' || !inSpan(motivationDay_(row.closedAt))) continue;
    var who = motivationCredited_(row, closers);
    if (!who.length) continue;
    // 頭数で割る。割らないと人ごとの合計を足しても全体に戻らない
    var share = gameIssuePoints_(row, kids) / who.length;
    for (var w = 0; w < who.length; w++) add(who[w], share);
  }

  var pulls = dbReadAll('pulls');
  var authors = {};
  for (var p = 0; p < pulls.length; p++) {
    authors[String(pulls[p].number)] = String(pulls[p].author || '');
    if (String(pulls[p].state) === 'merged' && inSpan(motivationDay_(pulls[p].mergedAt))) {
      add(String(pulls[p].author || ''), 2);
    }
  }

  // 同じ依頼には1人1回。最初の確認の日で数える
  var reviews = dbReadAll('reviews');
  var seen = {};
  for (var r = 0; r < reviews.length; r++) {
    var rv = reviews[r];
    var state = String(rv.state);
    if (state !== 'approve' && state !== 'request_changes') continue;
    var reviewer = String(rv.reviewer || '');
    if (!reviewer || reviewer === authors[String(rv.prNumber)]) continue;
    var key = String(rv.prNumber) + '|' + reviewer;
    if (seen[key]) continue;
    seen[key] = true;
    if (inSpan(motivationDay_(rv.at))) add(reviewer, 1);
  }

  for (var k in pts) pts[k] = Math.round(pts[k] * 10) / 10;
  return pts;
}

/**
 * 本人に見せたことのある最高のレベル。**下がらないようにするため**に覚える。
 * 鍵にアドレスを入れる (疑似GASの UserProperties は人で分かれない)。
 *
 * @param {string} email
 * @returns {number}
 */
function gameLevelSeen_(email) {
  var v = Number(PropertiesService.getUserProperties().getProperty('GAME_LEVEL_MAX:' + email));
  return isFinite(v) && v > 0 ? Math.floor(v) : 0;
}

/**
 * @param {string} email
 * @param {number} n
 */
function gameLevelSeenSet_(email, n) {
  PropertiesService.getUserProperties().setProperty('GAME_LEVEL_MAX:' + email, String(n));
}

/**
 * 本人の合計・今週・レベル・次のレベルまで・参加しているか。**順位は返さない**
 * (上位にいない人に「◯位」を見せると下位の印になる)。
 *
 * @param {string} email
 * @param {Date} now
 * @returns {{total: number, week: number, level: number, nextAt: number, playing: boolean}}
 */
function gameMine_(email, now) {
  var me = String(email || '');
  var span = motivationSpan_(now);
  var total = gamePointsByPerson_('', '')[me] || 0;
  var week = gamePointsByPerson_(span.weekStart, span.today)[me] || 0;
  var level = Math.max(gameLevel(total), gameLevelSeen_(me));
  return { total: total, week: week, level: level, nextAt: gameLevelAt(level + 1),
    playing: gamePlayers().indexOf(me) >= 0 };
}

/**
 * 今週の上位3位まで (参加している人だけ・0点は載らない・同点は同じ順位)。
 *
 * @param {Date} now
 * @returns {Array<{rank: number, email: string, name: string, points: number}>}
 */
function gameTop_(now) {
  var span = motivationSpan_(now);
  var pts = gamePointsByPerson_(span.weekStart, span.today);
  var list = gamePlayers()
    .filter(function (e) { return (pts[e] || 0) > 0; })
    .map(function (e) { return { email: e, points: pts[e] }; })
    .sort(function (a, b) { return b.points - a.points || (a.email < b.email ? -1 : 1); });

  var names = memberNames(list.map(function (x) { return x.email; }));
  var out = [];
  for (var i = 0; i < list.length; i++) {
    var rank = i > 0 && list[i].points === list[i - 1].points ? out[i - 1].rank : i + 1;
    if (rank > 3) break;
    out.push({ rank: rank, email: list[i].email, name: names[list[i].email], points: list[i].points });
  }
  return out;
}
```

```js
   * 帯の左の印。チェックの線を描き、進み具合があれば細い棒を出す。
   *
   * @param {{done?: number, total?: number}} mark
   * @returns {HTMLElement}

  function makeSnackMark(mark) {
    var box = document.createElement('span');
    box.className = 'snack-mark';
    box.setAttribute('aria-hidden', mark.total ? 'false' : 'true');

    var ns = 'http://www.w3.org/2000/svg';
    var svg = document.createElementNS(ns, 'svg');
    svg.setAttribute('viewBox', '0 0 24 24');
    svg.setAttribute('class', 'snack-check');
    var path = document.createElementNS(ns, 'path');
    path.setAttribute('d', 'M5 12l5 5L19 7');
    svg.appendChild(path);
    box.appendChild(svg);

    if (mark.total) {
      var track = document.createElement('span');
      track.className = 'snack-progress';
      track.setAttribute('role', 'progressbar');
      track.setAttribute('aria-valuemin', '0');
      track.setAttribute('aria-valuemax', String(mark.total));
      track.setAttribute('aria-valuenow', String(mark.done));
      var fill = document.createElement('span');
      fill.className = 'snack-progress-fill';
      // 前の値から1段伸びる。動きを減らす設定では CSS が transition を止める
      fill.style.width = Math.round(Math.max(mark.done - 1, 0) / mark.total * 100) + '%';
      track.appendChild(fill);
      box.appendChild(track);
      window.requestAnimationFrame(function () {
        fill.style.width = Math.round(mark.done / mark.total * 100) + '%';
      });
    }
    return box;
```

```js
   * 日報の「✅今日」の節の形にする。
   *
   * @param {Array<{kind: string, number: number, title: string}>} items
   * @returns {string}

  function todayReportText(items) {
    return ['✅今日'].concat(items.map(function (x) {
      return x.kind === 'pull'
        ? '- 確認依頼 #' + x.number + ' ' + x.title + ' を' + OFFICIAL + 'に反映'
        : '- #' + x.number + ' ' + x.title;
    })).join('\n');

  /**
   * 今日片づけたもの。**本人にだけ見える。** 件数は大きく出さず、題名を並べる
   * (件数を追わせると簡単なものから手を付ける)。
   *
   * @param {Array<{kind: string, number: number, title: string}>} items
   * @returns {HTMLElement}
   */
  function makeTodayCard(items) {
    var card = document.createElement('section');

      card.appendChild(none);
      return card;
    }

    var list = document.createElement('ul');
    list.className = 'my-today-list';
    items.forEach(function (x) {
      var li = document.createElement('li');

      list.appendChild(li);
    });

    var copy = document.createElement('button');
    copy.type = 'button';
    copy.className = 'btn';
    copy.textContent = '日報にコピー';
    copy.addEventListener('click', function () {
      var text = todayReportText(items);
      // 埋め込みの枠では写せないことがある。そのときは選んで写せる欄を出す
      function fallback() {
        var area = card.querySelector('textarea') || document.createElement('textarea');
        area.readOnly = true;
        area.className = 'my-today-copy';
        area.value = text;
        area.setAttribute('aria-label', '日報に貼る文');
        if (!area.parentNode) card.appendChild(area);
        area.select();
      }
      var clip = window.navigator.clipboard;
      if (!clip || !clip.writeText) { fallback(); return; }
      clip.writeText(text).then(function () {
        showSnack('日報の「✅今日」の形で写しました', { kind: 'ok' });
      }, fallback);
    });
    card.appendChild(copy);
    return card;
```
