# 手元の道具: 作業をやることに載せる・更新を知らせて自動で入れ替える Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 手元の道具 (`kit/`) の初回セットアップで、グローバルの `~/.claude` にフック2つとスキル1つを入れ、登録したフォルダでの Claude Code の作業を番頭のやることに載せる。道具は1日1回新しい版を確かめて自動で入れ替え、画面では古い道具を持つ人に「更新あり」を出す。

**Architecture:** 手元側は `kit/track/` に3つの ESM モジュール (`hook.mjs` = フック本体・単体で動く / `update.mjs` = 版の確認と入れ替え / `track.mjs` = 入れる・外す・フォルダ・会話の結び付け) と `SKILL.md` を置き、`agent.mjs` がそれを呼ぶ。番頭側はコマンドキューに読むだけの op `kitVersion` / `kitFiles` を足し、誰がどの指紋を持っているかをスクリプトプロパティに覚えて `apiKitStatus` で画面に返す。

**Tech Stack:** Node.js 18+ (ESM, 依存なし) / Google Apps Script / vitest 4 / jsdom

**Spec:** `docs/superpowers/specs/2026-10-15-kit-track-design.md`

## Global Constraints

- 手元の道具は**受け取った中身を実行しない**。入れ替えは書き換えるだけ。`kit/track/*.mjs` は `child_process` を import しない。`kit/agent.mjs` の `execFileSync(` は1件のまま (`test/agentkit.test.js`「この道具は頼みごとを実行しない」)
- 道具の置き場は `~/.banto/` (環境変数 `BANTO_HOME` で差し替え)。Claude Code の設定は `~/.claude/` (環境変数 `CLAUDE_CONFIG_DIR` で差し替え)。テストは必ず両方を一時フォルダに向ける
- `~/.claude` に**自動で**書くのは `skills/banto-track/SKILL.md` だけ。`settings.json` は `track install` / `track uninstall` のときだけ書き、書く前に `settings.json.banto-backup-<日時>` に控える。既存のフックと設定は消さない
- フックは番頭に問い合わせない (ファイルを読んで字を返すだけ)。何が起きても終了コード 0 で、作業を止めない
- 受け取ったファイル名で `..`・絶対パス・`\`・ドライブ名 (`C:`) を含むものは書かない
- 指紋 = `sha256(JSON.stringify(files))` の16進の先頭8字。番頭の `kitPrint_()` と手元の `kitPrintOf()` は同じ値を返すこと
- GAS 側: 画面に返すものは `plain*` を通す形 (文字列と真偽だけ)。email を受け取る関数は名前の末尾を `_` にする。api は Session の email だけを渡す
- 画面: `textContent` のみ。`call()` のみ。CSS は既存のトークンのみ (`--danger-solid` は定義済み)
- `kit/` を直したら `node scripts/build-kit.mjs` で `src/KitFiles.gs` を焼き直してから commit する (`test/agentkit.test.js`「kit/ を直したら焼き直しが要ると分かる」が見ている)。`src/KitFiles.gs` を手で直さない
- 直したら、直す前に戻して落ちることを確かめる (revert-to-fail)
- 言葉: 画面とメッセージに Git の言葉 (PR / マージ / Issue) を出さない。「やること」「確認依頼」「反映」
- デプロイは `npm run deploy` だけ (この計画の中ではしない)

## Spec からの決定 (Rulings)

計画を書く段階で、仕様のとおりでは動かない・危ない箇所を次のように決めた。仕様書にも同じことを書き足す (Task 5)。

- **R1 指紋の覚え先はスクリプトプロパティ** (`KIT_PRINT:<email 小文字>`)。仕様は UserProperties だが、コマンドキューは持ち主のトリガーで走るため、そこから他人の UserProperties には書けない。画面 (開いている本人として走る) とトリガーの両方から読み書きできるのはスクリプトプロパティだけ
- **R2 `track install` は道具を番頭から受け取って置く** (`kitFiles`)。展開した zip のフォルダを写すと、利用者のリポジトリの直下に展開していた場合に `.claude/` や `CLAUDE.md` まで巻き込む。番頭から受け取れば中身が zip と同じだと決まり、指紋も最初から分かる
- **R3 `setup` は尋ねない**。Claude Code は `setup` を端末なしで走らせるため、尋ねても答えられない。`setup` は入れ方を案内し、`track install` が端末なら y/N で尋ね、端末でなければ `--yes` を求める (Claude は利用者に確かめてから `--yes` を付ける)
- **R4 会話の id は合図に入れて渡す**。手元のコマンドからは会話の id が分からないため、UserPromptSubmit の合図に `この会話の id: <id>` を書き、`track set / touch / clear` は id を引数に取る。完了したら結び付きを外す `track clear` を足す
- **R5 スキルとフックは `kit/track/` に置く** (`kit/.claude/skills/` ではない)。`kit/.claude/skills/` の全スキルはスクラムの決まり (`node agent.mjs scrum` を含む) をテストで課されている。zip の中では `track/SKILL.md` / `track/hook.mjs`
- **R6 自動の確認は `~/.banto/kit/agent.mjs` として動いたときだけ**。入れ替えるのは `~/.banto/kit` なので、ほかの場所の写し (リポジトリの `kit/`、展開した zip) から確かめても意味が無く、テストが本物の命令の入れ先に命令を置く事故にもなる
- **R7 戻したら、その版を飛ばす** (`config.skipPrint`)。戻しても翌日の確認で同じ版が入り直すため。`agent update` (手で頼んだとき) は飛ばさない

## Review Focus

1. 利用者の `~/.claude/settings.json` に既に別のフックや設定がある / JSON が壊れている → 既存のものは1つも消えず、壊れていれば何も書かずに断る (Task 4 のテスト)
2. 登録外のフォルダ・壊れた入力・会話の id に `../` が入ったフック呼び出し → 何も出さず終了コード 0、`sessions/` の外に書かない (Task 2 のテスト)
3. 番頭から `../../.zshrc` や絶対パスの名前が届く → `~/.banto/kit` の外に1つも書かれない (Task 3 のテスト)
4. リポジトリの `kit/agent.mjs` をテストや手で動かす → 自動の確認は走らず、本物の入れ先に命令を置かない (Task 4 のテスト)
5. 届いた中身が途中で切れて指紋が合わない → 今の `~/.banto/kit` は1字も変わらず、控えも増えない (Task 3 のテスト)

`src/core/AgentKit.gs` — `agentKitName_` の上に足し、`agentKitName_` の指紋の行を `var print = kitPrint_();` に変える:

```js
/**
 * 配る中身の指紋。zip の名前と、手元の道具が古いかの判定に使う。
 *
 * **手元の道具 (kit/track/update.mjs の kitPrintOf) と同じ式でなければならない。**
 * 式が食い違うと、手元は毎日「新しい版がある」と読み、入れ替えを繰り返す。
 *
 * @returns {string} 16進8字
 */
function kitPrint_() {
  return sha256Hex(JSON.stringify(KIT_FILES())).substring(0, 8);
}

/**
 * その人が持っている道具の指紋を覚える。
 *
 * **スクリプトプロパティに置く。** 手元の道具からの命令は持ち主のトリガーで
 * 走るため、そこから利用者本人の UserProperties には書けない。
 *
 * @param {string} email
 * @param {string} print
 */
function kitRemember_(email, print) {
  var who = String(email || '').toLowerCase();
  if (!who || !/^[0-9a-f]{8}$/.test(String(print || ''))) return;
  PropertiesService.getScriptProperties().setProperty('KIT_PRINT:' + who, String(print));
}

/**
 * その人の道具が古いか。
 *
 * まだ一度も落としていない人は古いことにしない (札を出しても落とす理由が分からない)。
 *
 * @param {string} email
 * @returns {{print:string, mine:string, outdated:boolean}}
 */
function kitStatus_(email) {
  var print = kitPrint_();
  var who = String(email || '').toLowerCase();
  var mine = who
    ? String(PropertiesService.getScriptProperties().getProperty('KIT_PRINT:' + who) || '')
    : '';
  return { print: print, mine: mine, outdated: mine !== '' && mine !== print };
}
```

`src/core/CommandQueue.gs` — `COMMAND_OPS()` の `history:` の行のあとに足す:

     * 手元の道具が自分を新しくするための読むだけの命令。

#!/usr/bin/env node
/**
 * Claude Code のフック。登録したフォルダでの作業を、番頭 (SoftBanto) の
 * やることに載せるよう Claude に合図する。
 *
 *   node track-hook.mjs prompt   … UserPromptSubmit。決まりと、いまのやることを渡す
 *   node track-hook.mjs stop     … Stop。やることを更新せずに終えようとしたら1回だけ止める
 *
 * **番頭には問い合わせない。** 命令の返事は最大1分かかり、フックで待つと
 * 依頼のたびに Claude Code が止まる。ファイルを読んで字を返すだけにする。
 *
 * **何が起きても作業を止めない。** 例外は握り、終了コードは 0 のまま。
 *
 * このファイルは ~/.banto/hooks/track-hook.mjs に写して使う。ほかのファイルを
 * import しない (道具の入れ替えの途中でも動くように)。
 */

import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import process from 'node:process';
import { pathToFileURL } from 'node:url';

/** 道具の置き場。テストでは BANTO_HOME で差し替える */
export function bantoHome() {
  return process.env.BANTO_HOME || path.join(os.homedir(), '.banto');
}

function readJson(file, fallback) {
  try {
    return JSON.parse(fs.readFileSync(file, 'utf8'));
  } catch (e) {
    return fallback;
  }
}

/** 実体の道のり。/tmp と /private/tmp のような別名をそろえる */
function real(p) {
  try {
    return fs.realpathSync(p);
  } catch (e) {
    return path.resolve(p);
  }
}

/** @returns {string[]} 載せるフォルダ */
export function trackedFolders(home) {
  const t = readJson(path.join(home, 'tracked.json'), {});
  return t && Array.isArray(t.folders) ? t.folders.map(String) : [];
}

/** そのフォルダ (またはその下) を載せるか */
export function isTracked(home, cwd) {
  if (!cwd) return false;
  const here = real(String(cwd));
  return trackedFolders(home).some((f) => {
    const root = real(f);
    return here === root || here.startsWith(root.endsWith(path.sep) ? root : root + path.sep);
  });
}

/**
 * 会話ごとの覚え書きの道のり。id の記号は落とす (`../` で外に書かせない)。
 *
 * @returns {string} id が空になれば ''
 */
export function sessionFile(home, id) {
  const safe = String(id || '').replace(/[^A-Za-z0-9_-]/g, '');
  return safe ? path.join(home, 'sessions', safe + '.json') : '';
}

export function readSession(home, id) {
  const file = sessionFile(home, id);
  return file ? readJson(file, {}) || {} : {};
}

export function writeSession(home, id, patch) {
  const file = sessionFile(home, id);
  if (!file) return;
  fs.mkdirSync(path.dirname(file), { recursive: true });
  fs.writeFileSync(file, JSON.stringify({ ...readSession(home, id), ...patch }, null, 2));
}

/** 入れ替えの記録を、Claude に伝える1文にする */
function describeLog(log) {
  if (log.available) {
    return '番頭の道具に新しい版があります (' + log.available + ')。' +
      '`agent update` で入れられます。利用者に1行だけ伝えてください。';
  }
  const changed = Array.isArray(log.changed) ? log.changed : [];
  return '番頭の道具を自動で新しくしました (' + (log.version || '') + ')。変わったファイル: ' +
    (changed.join(', ') || 'なし') + '。戻すときは `agent update rollback`。利用者に1行だけ伝えてください。';
}

/**
 * UserPromptSubmit。登録したフォルダなら合図を返す。
 *
 * @param {string} home
 * @param {{cwd?:string, session_id?:string}} input
 * @param {Date} [now]
 * @returns {string} 出す JSON。出さないなら ''
 */
export function onPrompt(home, input, now) {
  if (!isTracked(home, input.cwd)) return '';
  const id = String(input.session_id || '');
  writeSession(home, id, { promptAt: (now || new Date()).toISOString() });

  const s = readSession(home, id);
  const lines = [
    'このフォルダの作業は 番頭 (SoftBanto) のやることに載せる決まりです。',
    'ファイル・設定・文書を作る・直す・消す依頼なら、banto-track スキルに従って起票・更新・完了してください。' +
      '質問・説明・調べもの・雑談は載せません。',
    'この会話の id: ' + id,
    '道具: node "' + path.join(home, 'kit', 'agent.mjs') + '"',
  ];
  if (s.issue) lines.push('いまのやること: #' + s.issue + (s.title ? ' (' + s.title + ')' : ''));

  const logFile = path.join(home, 'update-log.json');
  const log = readJson(logFile, null);
  if (log) {
    lines.push(describeLog(log));
    try { fs.unlinkSync(logFile); } catch (e) { /* 次に見せればよい */ }
  }

  return JSON.stringify({
    hookSpecificOutput: { hookEventName: 'UserPromptSubmit', additionalContext: lines.join('\n') },
  });
}

/**
 * Stop。いまのやることがあるのに、この返事のあいだに印が付いていなければ1回だけ止める。
 *
 * 止めたあとの2回目 (stop_hook_active) は止めない。止め続けると終われなくなる。
 *
 * @returns {string} 出す JSON。止めないなら ''
 */
export function onStop(home, input) {
  if (input.stop_hook_active) return '';
  if (!isTracked(home, input.cwd)) return '';
  const id = String(input.session_id || '');
  const s = readSession(home, id);
  if (!s.issue) return '';
  if (s.touchedAt && s.promptAt && String(s.touchedAt) >= String(s.promptAt)) return '';

  return JSON.stringify({
    decision: 'block',
    reason: '番頭のやること #' + s.issue + ' を、この作業に合わせて更新するか完了にしてください' +
      ' (banto-track スキル)。済んでいれば `agent track touch ' + id + '` で印を付けてください。',
  });
}

async function main() {
  const kind = process.argv[2];
  let input;
  try {
    input = JSON.parse(fs.readFileSync(0, 'utf8') || '{}');
  } catch (e) {
    return;
  }
  if (!input || typeof input !== 'object') return;

  const home = bantoHome();
  const out = kind === 'prompt' ? onPrompt(home, input)
    : kind === 'stop' ? onStop(home, input) : '';
  if (out) process.stdout.write(out + '\n');
}

// import されたときは動かない (track.mjs が関数を使う)
function isMain() {
  try {
    return Boolean(process.argv[1]) &&
      pathToFileURL(fs.realpathSync(process.argv[1])).href === import.meta.url;
  } catch (e) {
    return false;
  }
}

if (isMain()) {
  main().catch(() => {}).finally(() => { process.exitCode = 0; });
}

/**
 * 手元の道具を、番頭から新しい版を受け取って入れ替える。
 *
 * **入れ替えは書き換えるだけで、受け取った中身を実行しない。** 新しい
 * agent.mjs が動くのは、次に呼ばれたときである。
 *
 * 命令の入れ先 (Drive の queue/) は、Drive を共有している人なら誰でも書ける。
 * 偽の結果を置かれると、その人が書いたものが次に呼んだときに動く。この仕組みの
 * 中に本物か確かめる手段は無いので、次の手当てで代える:
 *   - 置き場 (~/.banto/kit) の外には書かない (safeName)
 *   - 入れ替える前に控えを取り、agent update rollback で戻せる
 *   - 何が変わったかを、次に Claude Code を開いたときに見せる
 *   - config.json の autoUpdate: false で、知らせるだけにできる
 *   - 指紋が名乗りと合わなければ入れない (途中で切れたものを防ぐ。偽物は防げない)
 */

import fs from 'node:fs';
import path from 'node:path';
import crypto from 'node:crypto';

export const DAY_MS = 24 * 60 * 60 * 1000;
const KEEP_BACKUPS = 3;

export function paths(home) {
  return {
    kit: path.join(home, 'kit'),
    config: path.join(home, 'config.json'),
    backup: path.join(home, 'backup'),
    log: path.join(home, 'update-log.json'),
    hooks: path.join(home, 'hooks'),
  };
}

export function readConfig(home) {
  try {
    return JSON.parse(fs.readFileSync(paths(home).config, 'utf8'));
  } catch (e) {
    return null;
  }
}

export function writeConfig(home, patch) {
  fs.mkdirSync(home, { recursive: true });
  fs.writeFileSync(paths(home).config,
    JSON.stringify({ ...(readConfig(home) || {}), ...patch }, null, 2) + '\n');
}

/**
 * 中身の指紋。**番頭の kitPrint_() と同じ式でなければならない。**
 *
 * @param {Object<string,string>} files 名前 → base64
 * @returns {string} 16進8字
 */
export function kitPrintOf(files) {
  return crypto.createHash('sha256').update(JSON.stringify(files), 'utf8').digest('hex').slice(0, 8);
}

/**
 * 受け取った名前を、置き場の中の道のりにする。外を指すものは null。
 *
 * @param {string} name
 * @returns {string|null}
 */
export function safeName(name) {
  const s = String(name || '');
  if (!s || s.includes('\\') || s.includes('\0')) return null;
  if (path.posix.isAbsolute(s) || /^[A-Za-z]:/.test(s)) return null;
  const norm = path.posix.normalize(s);
  if (norm === '.' || norm.split('/').includes('..')) return null;
  return norm;
}

/** 並べると古い順になる日時の字 (20261015-093000) */
export function stamp(now) {
  return new Date(now).toISOString().replace(/[-:]/g, '').replace(/\..*$/, '').replace('T', '-');
}

/** フォルダの中のファイルを、名前 → 中身 (字) で読む */
function snapshot(dir) {
  const out = {};
  if (!fs.existsSync(dir)) return out;
  (function visit(rel) {
    for (const name of fs.readdirSync(path.join(dir, rel))) {
      const next = rel ? rel + '/' + name : name;
      const at = path.join(dir, next);
      if (fs.statSync(at).isDirectory()) visit(next);
      else out[next] = fs.readFileSync(at, 'utf8');
    }
  })('');
  return out;
}

/** 番頭に作業を載せる仕掛けを入れているか */
export function claudeLinked(claude) {
  return fs.existsSync(path.join(claude, 'skills', 'banto-track'));
}

/**
 * 置き場の中のスキルとフックを、使われる場所に写す。
 *
 * **~/.claude に自動で書くのはこのスキル1つだけ。** settings.json は触らない。
 */
export function linkClaude(home, claude) {
  const kit = paths(home).kit;
  const skill = path.join(kit, 'track', 'SKILL.md');
  const hook = path.join(kit, 'track', 'hook.mjs');
  if (fs.existsSync(skill)) {
    const to = path.join(claude, 'skills', 'banto-track');
    fs.mkdirSync(to, { recursive: true });
    fs.copyFileSync(skill, path.join(to, 'SKILL.md'));
  }
  if (fs.existsSync(hook)) {
    fs.mkdirSync(paths(home).hooks, { recursive: true });
    fs.copyFileSync(hook, path.join(paths(home).hooks, 'track-hook.mjs'));
  }
}

function listBackups(home) {
  const dir = paths(home).backup;
  return fs.existsSync(dir) ? fs.readdirSync(dir).filter((n) => /^\d{8}-\d{6}/.test(n)).sort() : [];
}

function backupKit(home, now, print) {
  const p = paths(home);
  if (!fs.existsSync(p.kit)) return;
  let name = stamp(now);
  // 同じ秒に2回入れ替えたときに前の控えを上書きしない
  for (let i = 1; fs.existsSync(path.join(p.backup, name)); i++) name = stamp(now) + '-' + i;
  const to = path.join(p.backup, name);
  fs.cpSync(p.kit, to, { recursive: true });
  fs.writeFileSync(path.join(to, 'backup.json'), JSON.stringify({ print: print || '' }));
  const all = listBackups(home);
  for (const old of all.slice(0, Math.max(0, all.length - KEEP_BACKUPS))) {
    fs.rmSync(path.join(p.backup, old), { recursive: true, force: true });
  }
}

/**
 * 番頭から中身を受け取って置き場を入れ替える。
 *
 * @param {{home:string, claude:string, send:Function, now?:number, link?:boolean}} o
 *   link: スキルとフックを必ず写す (入れるとき)。偽なら、入れている人だけ写す
 * @returns {Promise<{print:string, version:string, changed:string[]}>}
 */
export async function installFromServer({ home, claude, send, now = Date.now(), link = false }) {
  const res = await send('kitFiles', {});
  if (!res || !res.ok) throw new Error('道具を受け取れませんでした: ' + ((res && res.error) || '返事がありません'));
  const result = res.result || {};
  const files = result.files || {};
  const print = String(result.print || '');
  const version = String(result.version || '');
  if (!print || kitPrintOf(files) !== print) {
    throw new Error('受け取った道具の指紋が合いません。入れ替えませんでした');
  }

  const p = paths(home);
  const before = snapshot(p.kit);
  backupKit(home, now, (readConfig(home) || {}).kitPrint);

  // 新しい置き場を隣に組んでから差し替える。途中で落ちても今の置き場は残る
  const next = p.kit + '.new';
  fs.rmSync(next, { recursive: true, force: true });
  fs.mkdirSync(next, { recursive: true });
  const written = {};
  for (const [name, body] of Object.entries(files)) {
    const safe = safeName(name);
    if (!safe) continue;
    const to = path.join(next, ...safe.split('/'));
    fs.mkdirSync(path.dirname(to), { recursive: true });
    const bytes = Buffer.from(String(body), 'base64');
    fs.writeFileSync(to, bytes);
    written[safe] = bytes.toString('utf8');
  }
  fs.rmSync(p.kit, { recursive: true, force: true });
  fs.renameSync(next, p.kit);

  if (link || claudeLinked(claude)) linkClaude(home, claude);

  const names = new Set([...Object.keys(before), ...Object.keys(written)]);
  const changed = [...names].filter((n) => before[n] !== written[n]).sort();
  writeConfig(home, { kitPrint: print, kitVersion: version, skipPrint: '' });
  return { print, version, changed };
}

/**
 * 新しい版が来ていないか確かめ、来ていれば入れ替える。
 *
 * @param {{home:string, claude:string, send:Function, now?:number, force?:boolean}} o
 *   force: 24時間を待たず、飛ばした版も入れる (agent update)
 */
export async function checkForUpdate({ home, claude, send, now = Date.now(), force = false }) {
  const config = readConfig(home);
  if (!config) return { checked: false, updated: false };
  const last = Date.parse(config.lastUpdateCheck || '');
  if (!force && Number.isFinite(last) && now - last < DAY_MS) return { checked: false, updated: false };

  // 先に書く。向こうが止まっていても、命令のたびに待たせない
  writeConfig(home, { lastUpdateCheck: new Date(now).toISOString() });

  const res = await send('kitVersion', { mine: config.kitPrint || '' });
  if (!res || !res.ok) throw new Error('道具の版を確かめられませんでした: ' + ((res && res.error) || '返事がありません'));
  const print = String((res.result || {}).print || '');
  const version = String((res.result || {}).version || '');
  const at = new Date(now).toISOString();

  if (!print || print === config.kitPrint) return { checked: true, updated: false };
  if (!force && print === config.skipPrint) return { checked: true, updated: false, skipped: true };
  if (!force && config.autoUpdate === false) {
    fs.writeFileSync(paths(home).log, JSON.stringify({ available: version, at }));
    return { checked: true, updated: false, available: true, version };
  }

  const done = await installFromServer({ home, claude, send, now });
  fs.writeFileSync(paths(home).log, JSON.stringify({ version: done.version, changed: done.changed, at }));
  return { checked: true, updated: true, ...done };
}

/**
 * 最後の控えに戻す。戻した版は、翌日の確認で入れ直さない。
 *
 * @returns {{restored:string}}
 */
export function rollback({ home, claude }) {
  const p = paths(home);
  const all = listBackups(home);
  if (!all.length) throw new Error('戻せる控えがありません');
  const last = all[all.length - 1];
  const dir = path.join(p.backup, last);
  let meta = {};
  try { meta = JSON.parse(fs.readFileSync(path.join(dir, 'backup.json'), 'utf8')); } catch (e) { meta = {}; }
  const config = readConfig(home) || {};

  fs.rmSync(p.kit, { recursive: true, force: true });
  fs.cpSync(dir, p.kit, { recursive: true });
  fs.rmSync(path.join(p.kit, 'backup.json'), { force: true });
  if (claudeLinked(claude)) linkClaude(home, claude);

  writeConfig(home, { kitPrint: meta.print || '', skipPrint: config.kitPrint || '' });
  fs.rmSync(dir, { recursive: true, force: true });
  return { restored: last };
}

/**
 * 番頭に作業を載せる仕掛けを、Claude Code に入れる・外す。
 *
 * 入れるもの:
 *   ~/.claude/settings.json の hooks に2つ (UserPromptSubmit / Stop)。既存は残す
 *   ~/.claude/skills/banto-track/SKILL.md
 *   ~/.banto/ (道具の本体・設定・載せるフォルダ・会話ごとの覚え書き)
 *
 * **settings.json を書くのは、人が ok した install / uninstall のときだけ。**
 * 書く前に settings.json.banto-backup-<日時> に控える。
 */

import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import process from 'node:process';
import { trackedFolders, writeSession } from './hook.mjs';
import { installFromServer, readConfig, writeConfig, stamp } from './update.mjs';

/** Claude Code の設定の置き場。テストでは CLAUDE_CONFIG_DIR で差し替える */
export function claudeHome() {
  return process.env.CLAUDE_CONFIG_DIR || path.join(os.homedir(), '.claude');
}

export function hookCommand(home, kind) {
  return 'node "' + path.join(home, 'hooks', 'track-hook.mjs') + '" ' + kind;
}

const EVENTS = [['UserPromptSubmit', 'prompt'], ['Stop', 'stop']];

function readSettings(file) {
  if (!fs.existsSync(file)) return { settings: {}, text: null };
  const text = fs.readFileSync(file, 'utf8');
  try {
    const settings = text.trim() ? JSON.parse(text) : {};
    if (!settings || typeof settings !== 'object' || Array.isArray(settings)) throw new Error('not object');
    return { settings, text };
  } catch (e) {
    throw new Error(file + ' を読めません (JSON として壊れています)。直してからもう一度実行してください。何も変えていません');
  }
}

function hooksOf(settings) {
  if (!settings.hooks || typeof settings.hooks !== 'object' || Array.isArray(settings.hooks)) settings.hooks = {};
  return settings.hooks;
}

/**
 * settings.json にフックを2つ足す。既にあれば足さない。
 *
 * @returns {{file:string, backup:string, added:number}}
 */
export function installHooks({ home, claude, now = Date.now() }) {
  const file = path.join(claude, 'settings.json');
  const { settings, text } = readSettings(file);
  const hooks = hooksOf(settings);
  let added = 0;
  for (const [event, kind] of EVENTS) {
    const cmd = hookCommand(home, kind);
    const groups = Array.isArray(hooks[event]) ? hooks[event] : [];
    const has = groups.some((g) => g && Array.isArray(g.hooks) && g.hooks.some((h) => h && h.command === cmd));
    if (!has) {
      groups.push({ hooks: [{ type: 'command', command: cmd, timeout: 5 }] });
      added++;
    }
    hooks[event] = groups;
  }
  if (!added) return { file, backup: '', added };

  let backup = '';
  if (text !== null) {
    backup = file + '.banto-backup-' + stamp(now);
    fs.writeFileSync(backup, text);
  }
  fs.mkdirSync(claude, { recursive: true });
  fs.writeFileSync(file, JSON.stringify(settings, null, 2) + '\n');
  return { file, backup, added };
}

/**
 * 足したフックとスキルだけを外す。~/.banto は残す (載せるフォルダや控えを失わないため)。
 *
 * @returns {{removed:number}}
 */
export function uninstallHooks({ home, claude, now = Date.now() }) {
  const file = path.join(claude, 'settings.json');
  let removed = 0;
  if (fs.existsSync(file)) {
    const { settings, text } = readSettings(file);
    const hooks = hooksOf(settings);
    for (const [event, kind] of EVENTS) {
      const cmd = hookCommand(home, kind);
      if (!Array.isArray(hooks[event])) continue;
      const kept = [];
      for (const g of hooks[event]) {
        if (!g || !Array.isArray(g.hooks)) { kept.push(g); continue; }
        const rest = g.hooks.filter((h) => !(h && h.command === cmd));
        removed += g.hooks.length - rest.length;
        if (rest.length) kept.push({ ...g, hooks: rest });
      }
      if (kept.length) hooks[event] = kept;
      else delete hooks[event];
    }
    if (!Object.keys(hooks).length) delete settings.hooks;
    if (removed) {
      fs.writeFileSync(file + '.banto-backup-' + stamp(now), text);
      fs.writeFileSync(file, JSON.stringify(settings, null, 2) + '\n');
    }
  }
  fs.rmSync(path.join(claude, 'skills', 'banto-track'), { recursive: true, force: true });
  return { removed };
}

function writeTracked(home, folders) {
  fs.mkdirSync(home, { recursive: true });
  fs.writeFileSync(path.join(home, 'tracked.json'), JSON.stringify({ folders }, null, 2) + '\n');
}

export function addFolder(home, dir) {
  const abs = path.resolve(dir || process.cwd());
  const list = trackedFolders(home);
  if (!list.includes(abs)) list.push(abs);
  writeTracked(home, list);
  return list;
}

export function removeFolder(home, dir) {
  const abs = path.resolve(dir || process.cwd());
  const list = trackedFolders(home).filter((f) => f !== abs);
  writeTracked(home, list);
  return list;
}

function needSession(session) {
  if (!String(session || '').replace(/[^A-Za-z0-9_-]/g, '')) {
    throw new Error('会話の id を渡してください (依頼のたびの合図に「この会話の id」として出ています)');
  }
}

/** 会話にやることを結び付ける。結び付けたことが印にもなる */
export function setIssue(home, session, number, title, now = new Date()) {
  needSession(session);
  const n = Number(number);
  if (!Number.isInteger(n) || n <= 0) throw new Error('番号は 1 以上の整数で渡してください: ' + number);
  writeSession(home, session, { issue: n, title: String(title || ''), touchedAt: now.toISOString() });
}

/** やることを更新した印を付ける (Stop フックが促さなくなる) */
export function touch(home, session, now = new Date()) {
  needSession(session);
  writeSession(home, session, { touchedAt: now.toISOString() });
}

/** 完了したやることを会話から外す */
export function clearIssue(home, session, now = new Date()) {
  needSession(session);
  writeSession(home, session, { issue: null, title: '', touchedAt: now.toISOString() });
}

/**
 * まとめて入れる: 設定を写し、道具を番頭から受け取り、フックを足す。
 *
 * 道具は手元の展開先を写さずに番頭から受け取る。展開先が利用者のリポジトリの
 * 直下だと、写すときに .claude/ や CLAUDE.md まで巻き込むため。
 */
export async function trackInstall({ home, claude, config, send, now = Date.now() }) {
  if (!config || !config.queueDir || !fs.existsSync(config.queueDir)) {
    throw new Error('命令の入れ先が見つかりません。先に node agent.mjs setup の案内どおりに設定してください');
  }
  const before = readConfig(home) || {};
  writeConfig(home, {
    queueDir: config.queueDir,
    webAppUrl: config.webAppUrl || before.webAppUrl || '',
    scriptUrl: config.scriptUrl || before.scriptUrl || '',
    autoUpdate: before.autoUpdate !== false,
  });
  const kit = await installFromServer({ home, claude, send, now, link: true });
  writeConfig(home, { lastUpdateCheck: new Date(now).toISOString() });
  const hooks = installHooks({ home, claude, now });
  return { kit, hooks };
}

/**
 * 1日1回、道具の新しい版を確かめる。本来の命令の結果は変えない。
 *
 * 出すのは標準エラーだけ。標準出力は Claude が読む結果である。

async function maybeUpdate() {
  if (!runningFromBanto()) return;
  const home = bantoHome();
  const config = update.readConfig(home);
  if (!config || !config.queueDir) return;
  try {
    const r = await update.checkForUpdate({ home, claude: track.claudeHome(), send: sender(config) });
    if (r.updated) process.stderr.write('番頭の道具を新しくしました (' + r.version + ')。戻すときは agent update rollback\n');
  } catch (e) {
    process.stderr.write('道具の新しい版を確かめられませんでした: ' + (e.message || e) + '\n');
  }
}

async function confirmInstall(rest) {
  const plan = [
    '次のものを入れます:',
    '  ' + path.join(track.claudeHome(), 'settings.json') + ' の hooks に2つ (今の設定は控えを取って残します)',
    '  ' + path.join(track.claudeHome(), 'skills', 'banto-track', 'SKILL.md'),
    '  ' + bantoHome() + ' (道具の本体と設定)',
  ].join('\n');
  if (rest.includes('--yes')) return true;
  process.stdout.write(plan + '\n');
  if (!process.stdin.isTTY) {
    process.stderr.write('入れてよいか尋ねられませんでした。--yes を付けて実行してください' +
      ' (Claude に頼むときは、利用者に確かめてから --yes を付ける)\n');
    process.exitCode = 2;
    return false;
  }
  const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
  const answer = await rl.question('入れますか [y/N] ');
  rl.close();
  return /^y/i.test(answer.trim());
}

async function runTrack(rest) {
  const home = bantoHome();
  const claude = track.claudeHome();
  const [sub, ...a] = rest;

  if (sub === 'install') {
    if (!(await confirmInstall(a))) return;
    const config = loadConfig();
    const r = await track.trackInstall({ home, claude, config, send: sender(config) });
    process.stdout.write('入れました (道具 ' + r.kit.version + ')。' +
      '載せるフォルダは node agent.mjs track add <フォルダ> で選んでください\n');
    return;
  }
  if (sub === 'uninstall') {
    track.uninstallHooks({ home, claude });
    process.stdout.write('フックとスキルを外しました (' + home + ' は残してあります)\n');
    return;
  }
  if (sub === 'add') { process.stdout.write(track.addFolder(home, a[0]).join('\n') + '\n'); return; }
  if (sub === 'remove') { process.stdout.write(track.removeFolder(home, a[0]).join('\n') + '\n'); return; }
  if (sub === 'list') {
    const list = trackedFolders(home);
    process.stdout.write((list.length ? list.join('\n') : '(載せるフォルダはありません)') + '\n');
    return;
  }
  if (sub === 'set') { track.setIssue(home, a[0], a[1], a[2]); return; }
  if (sub === 'touch') { track.touch(home, a[0]); return; }
  if (sub === 'clear') { track.clearIssue(home, a[0]); return; }

  process.stderr.write('track の後には install / uninstall / add / remove / list / set / touch / clear のどれかを書いてください\n');
  process.exitCode = 2;
}

async function runUpdate(rest) {

  const claude = track.claudeHome();

  process.stdout.write(r.updated
    ? '新しくしました (' + r.version + '): ' + (r.changed.join(', ') || '変わったファイルなし') + '\n'
    : 'いまの道具が最新です\n');
}

# 番頭のやることに作業を載せる

依頼のたびの合図に「このフォルダの作業は 番頭 (SoftBanto) のやることに載せる決まりです」と出ているときだけ使う。
合図には `この会話の id: <id>` と `道具: node "<…>/agent.mjs"` が出ている。以下の `<id>` と `node "<道具>"` はそれに置き換える。

## 載せる依頼・載せない依頼

- **載せる**: ファイル・設定・文書を作る・直す・消す依頼。1つの依頼を1件にする
- **載せない**: 質問・説明・調べもの・雑談・確認だけの依頼

いまのやること (`いまのやること: #N`) が合図に出ていて、同じ依頼の続きなら、新しく起票せずにそれを使う。

## 手順

1. **起票**: `node "<道具>" issue "<題名>" "<本文>"` を**バックグラウンドで**走らせる (返事に最大1分かかる。待っているあいだに作業を進める)
   - 題名は依頼を40字以内でまとめたもの。本文は依頼の要約・フォルダ名・関係するリンク
   - 返ってきた番号で `node "<道具>" track set <id> <番号> "<題名>"` を実行して会話に結び付ける
2. **着手**: `node "<道具>" board <番号> "In Progress"`
3. **確認を頼んだとき** (確認依頼や PR を出したとき): `node "<道具>" board <番号> "In Review"` と `node "<道具>" issue-say <番号> "<一言とリンク>"`
4. **完了**: 依頼が終わったと言えるとき (反映や公開まで要る作業ならそこまで) に `node "<道具>" issue-close <番号>`、続けて `node "<道具>" track clear <id>`
   - 途中で止めるときは開いたまま、どこまでやったかを `issue-say` で残す
5. どの操作のあとも `node "<道具>" track touch <id>` で印を付ける (返事の終わりに促されなくなる)

## 届かないとき

命令の入れ先が無い・1分で返らないなどで番頭に届かないときは、**作業を止めない**。
利用者に「番頭に載せられませんでした (<理由>)」と1行だけ伝えて、依頼そのものを進める。
```

### 道具の自動更新

`~/.banto/kit/agent.mjs` は、1日1回、どの命令のあとでも番頭に新しい版を確かめ、あれば**自動で入れ替えます**
(書き換えるだけで、その場では実行しません。新しい版が動くのは次に呼ばれたとき)。

- 入れ替えたら、次に Claude Code を開いたときに何が変わったかが合図に出ます。利用者に1行だけ伝えてください
- 戻す: `node agent.mjs update rollback` (戻した版は自動では入れ直しません)。今すぐ確かめる: `node agent.mjs update`
- **危険**: 命令の入れ先 (Drive の queue/) は、Drive を共有している人なら誰でも書けます。偽の返事を置かれると、
  その人が書いたものが全員の手元で動きえます。受け取った中身が本物かを確かめる手段はありません
- 切る: `~/.banto/config.json` に `"autoUpdate": false` と書くと、新しい版があることを知らせるだけになります
```
