# エージェンティックスクラム

`CLAUDE.md` から分けた。下に挙げた場所を触る前に読むこと (`CLAUDE.md` の「触る場所と、先に読むファイル」)。

## エージェンティックスクラムは既定でオフ

`ai-scrum-gas` から取り入れた (`docs/superpowers/plans/2026-10-07-agentic-scrum.md`)。
**使わない人が多いので既定はオフ。** スクリプトプロパティ `SCRUM_ENABLED` が
`'true'` のときだけオンで、切り替えるのは管理者 (`apiSetScrumEnabled` が `repoAssertAdmin_` で確かめる。画面の「設定」)。

- オフのあいだ、スクラムの API と命令は `scrumAssertEnabled_()` で断り、画面には
  行き先も欄も出さない。**状態を見る `scrumState` だけはオフでも通す** (オンに
  するよう案内するため)。切り替える命令は置かない
- **データは台帳に置く。** PBI はやること (`issues` の末尾に sprint / points /
  acceptance)、ほかに sprints / impediments / impediment_comments / change_log。
  ai-scrum-gas の CSV は持たない
- **数は台帳から数える** (`ScrumView.js`)。ベロシティやバーンダウンを手で書く
  場所を作らない。手で書いた数は必ずずれる
- **終わったスプリントは、終わりの日の時点の中身で数える** (`scrumSprintMoves`)。
  いまの所属で数えると、終わらなかったやることを次へ移した時点で前のスプリントの
  計画から消え、移したぶんが持ち越しとして数えられない。移したことは変更の履歴 (`field: sprint`) に
  残っている。バーンダウンもその日ごとの中身で描く。**終わったスプリントへ後から
  入れた記録は、始まりから入っていたものとして読む** (読まないと、過去を後から
  書き入れたとき過去のベロシティが全部0になる。実際にそうなった)
- 文章の成果物 (スプリントの記録・振り返り・依頼書・仕様) は手元の `scrum/` に
  書く。台帳に入れると人が読む場所が増える
- 履歴 (`historyRecord_`) は通知と同じく、失敗しても本処理を巻き戻さない
- 手元の道具の `kit/.claude/` (スキル・エージェント)、`kit/SCRUM.md` (読み替え)、
  `kit/scrum-templates/` (ひな形) は `build-kit.mjs` がフォルダごと拾う。
  **ひな形を `scrum/` という名前で配らない。** zip を落とし直して展開したとき、
  チームが書き足した `scrum/` を上書きする
- スクラムと関係の無いもの (セキュリティ監査・ブラウザ操作) は取り入れない
- **人に見せる言葉は `TERMS()` (`src/core/Terms.js`) が唯一の定義** (#21)。既定は一般の言葉
  (作業期間・困りごと…)、自分の設定 `terms.style` で「スクラムの言葉」を選んだ人にだけスクラムの言葉で出す。
  画面は写し (`term` / `termFill`。`test/ui-parity.test.js`) を `termOf(key)` / `termIn('…{key}…')` で通し、
  **字を直に書かない** (`test/terms.test.js` がコメントを除いて走査する)。静の HTML は `data-term` に置き、
  `applyTerms` が埋める (描いた字も `termText` で印を付けると埋め直る)。文ごと両方の形を持たず、言葉だけを差し込む。
  表し方が変わっても**取り直さない** (`refreshTerms` は最後の返事から描き直す)。サーバが人ごとに変わる名前を
  渡すときは `{key}` のまま渡し、画面が埋める (`PREF_START_TABS_`)。用語の説明 (`SCRUM_GLOSSARY`) は
  TERMS の key で引く (見出しの字は人で変わる)。ゲームのポイントは別物なので変えない。
  台帳の列名・API 名・データ・`kit/` (エンジニア向け) も変えない
- **サーバの文 (断り・知らせ・説明) は一般の言葉に固定する。** 人ごとに切り替えると、キューやトリガーから
  出る文の言葉がばらつく。`test/terms.test.js` がスクラムの言葉が混ざっていないかを見ている
  (エディタで動かす `debug*` は持ち主だけが読むので除く)
