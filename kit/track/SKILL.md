# 番頭のやることに作業を載せる

依頼のたびの合図に「このフォルダの作業は 番頭 (SoftBanto) のやることに載せる決まりです」と出ているときだけ使う。
合図には `この会話の id: <id>` と `道具: node "<…>/agent.mjs"` が出ている。以下の `<id>` と `node "…/agent.mjs"` は、合図に出ている字に置き換える。

## 載せる依頼・載せない依頼

- **載せる**: ファイル・設定・文書を作る・直す・消す依頼。1つの依頼を1件にする
- **載せない**: 質問・説明・調べもの・雑談・確認だけの依頼

いまのやること (`いまのやること: #N`) が合図に出ていて、同じ依頼の続きなら、新しく起票せずにそれを使う。

## 手順

0. **始める前に** `node "…/agent.mjs" mine` で自分の番を見る (**バックグラウンドで**。待たせている確認依頼や期限切れがあれば、作業の前に利用者へ1行で伝える)
1. **起票**: `node "…/agent.mjs" issue "<題名>" "<本文>"` を**バックグラウンドで**走らせる (返事に最大1分かかる。待っているあいだに作業を進める)
   - 題名は依頼を40字以内でまとめたもの。本文は依頼の要約・フォルダ名・関係するリンク
   - 返ってきた番号で `node "…/agent.mjs" track set <id> <番号> <題名>` を実行して会話に結び付ける
2. **着手**: `node "…/agent.mjs" board <番号> "In Progress"`
3. **確認を頼んだとき** (確認依頼などを出したとき): `node "…/agent.mjs" board <番号> "In Review"` と `node "…/agent.mjs" issue-say <番号> "<一言とリンク>"`
4. **完了**: 依頼が終わったと言えるとき (反映や公開まで要る作業ならそこまで) に `node "…/agent.mjs" issue-close <番号>`、続けて `node "…/agent.mjs" track clear <id>`
   - 途中で止めるときは開いたまま、どこまでやったかを `issue-say` で残す
5. どの操作のあとも `node "…/agent.mjs" track touch <id>` で印を付ける (返事の終わりに促されなくなる)

## 届かないとき

命令の入れ先が無い・1分で返らないなどで番頭に届かないときは、**作業を止めない**。
利用者に「番頭に載せられませんでした (<理由>)」と1行だけ伝えて、依頼そのものを進める。
理由が分からなければ `node "…/agent.mjs" doctor` (番頭に頼まないのですぐ返る) の「直すこと」を添える。
