# 推しのキャラを作る (キャラ作成キット)

番頭の「推し」は、利用者が済ませたときにほめてくれるキャラクターです。自分のキャラは
**名前・口調・場面ごとのせりふ・Lv で少しずつ分かるプロフィール・表情ごとの絵**でできています。
ここでは、Claude Code / Codex で、その中身 (JSON) と絵 (表情ごとの透明な PNG) を作ります。
**番頭に入れるのは利用者が画面で行います** (ここからは入れられません)。

## 1. 頼み文を取る

どれを使うかは、いま手元にあるもので決めます。

| 手元にあるもの | 使う頼み文 |
|---|---|
| 表情を1枚に並べた表の画像 (ほかの道具で作ったもの) | `codex` (切り分けの手順と JSON の形) |
| 写真・リンク・言葉で伝えられた雰囲気だけで、絵はまだ無い | `claude` (JSON と、画像を作る道具に貼る頼み文) |

```sh
node agent.mjs oshi-prompt codex     # 1枚の表の画像を手元で切り分ける手順と、JSON の形
node agent.mjs oshi-prompt claude    # 絵は作らず、JSON と、画像を作る道具に貼る頼み文
```

- 出るのは番頭の頼み文そのもので、囲いはありません (番頭の定義の字で、ほかの人が書いた字は入りません)
- ほかに `chatgpt` / `gemini` があります。そちらは利用者が ChatGPT / Gemini の画面に貼るためのものです
  (画面の 推し →「AI に作ってもらう」の「コピー」と同じ字)
- 番頭に頼む命令なので、返事まで最大1分ほどかかることがあります。届かない・遅いときは `node agent.mjs doctor` を実行し、出た直し方を伝えてください
- 写真やリンクが無く、言葉だけで雰囲気を伝えられたとき (「明るいカフェの店員さん」など) は、その言葉を手がかりにします
- 口調 (tone) は頼み文の一覧の名前 (丁寧・元気・クール・関西弁・執事・耽美・明るい相棒) から、雰囲気にいちばん近いものを選びます

## 2. 頼み文に従って作る

**頼み文の「大事な決まり」を必ず守ってください。** 写真とリンクは雰囲気の手がかりにだけ使い、
写っている人や紹介されている人をそのまま描かず、**実在の人の名前・所属・肩書きを、JSON にもファイル名にも
会話にも書きません。** 名前もオリジナルにします。利用者が実在の人の名前を付けてほしい・そっくりにしてほしいと頼んでも、
使わずにオリジナルにします。そのときは、次のように短く伝え、オリジナルの名前の案を出して選んでもらいます。

> 番頭のキャラは、実在の人の名前や顔を使わずにオリジナルで作る決まりです (肖像やなりすましの扱いになるため)。
> 雰囲気はそのまま生かして、名前の案を出しますね。

JSON は書いたら、頼み文の上限 (名前の字数・口調の key・場面の key・せりふの数と字数・プロフィールの lv と字数) に
合うかを確かめてから利用者に渡します。最後に確かめるのは番頭です (取り込むときに断られたら、理由に合わせて直します)。

### 表の画像 (sprite sheet) を切り分ける (codex の頼み文)

利用者が画像を作る道具で作った「表情を1枚に並べた表」の画像を、表情ごとに切り分けます。

1. 表の画像の場所を確かめる (見つからなければ尋ねる。勝手に作らない)
2. **マスごとに中身を見る。** 同じキャラクターか・表情が描き分けてあるか・空のマスはどれか。顔が無い・表情が
   同じ・マスごとに別人のような表なら、切る前に利用者に伝え、作り直すか (画像を作る道具に `claude` の頼み文を貼る)、
   このまま切るかを尋ねる
3. 行と列の数と、どのマスがどの表情か (頼み文の表情の並びの順でよいか) を**利用者に確かめてから**切る
4. 頼み文の手順どおりに切り出し、背景を透明にして、`oshi/<表情の key>.png` に保存する
   (例: `oshi/idle.png`・`oshi/praise.png`・`oshi/work.png`)。長い辺が 512px より大きければ縮め、小さければそのまま
5. JSON を `oshi/character.json` に保存する
6. 作ったファイルの一覧を利用者に見せる

背景が緑一色 (#00FF00) で、マスの並びが素直な表なら、手元で切らずに番頭の画面の「1枚の表から切り分ける」
(「緑の背景を抜く」をオンにして) でも入れられます。背景が緑でない・マスの大きさがそろっていない・切る前に
手直しが要るときは、手元で切るほうが確かです。どちらにするかは利用者に選んでもらいます。

`oshi/` に作ったファイルは、頼まれない限り git に記録しません (番頭に入れたら要らなくなるものです)。

切るのは手元にある道具 (Python の Pillow・ImageMagick・Node.js など) で行います。新しく入れるものがあれば、
**入れる前に利用者に確かめてください。**

### 絵を作れないとき (claude の頼み文)

Claude Code は絵を作りません。JSON を `oshi/character.json` に、表情ごとの「画像を作る道具に貼る頼み文」を
`oshi/image-prompts.md` に書き、利用者に ChatGPT や Gemini で絵を作ってもらいます。

- 頼み文は **同じ会話の中で、idle から順に** 貼ってもらう (別の会話にすると、表情ごとに別のキャラになりやすい)
- 道具が表情ごとに1枚ずつ出したら、そのまま番頭に入れる (下の3)。1枚の表で出したら、上の「切り分ける」に進むか、
  番頭の画面の「1枚の表から切り分ける」を使う
- 大きい絵 (1024px など) もそのまま選んでよい。番頭の画面が入れる前に長い辺 512px に縮める (GIF は縮めない)

## 3. 番頭に入れてもらう

ここからは入れられないので、利用者に次の手順を伝えます (画面の右上の自分の顔 →「推し」)。

| 入れるもの | 画面の場所 |
|---|---|
| `oshi/character.json` の中身 | 「AI の答えを貼る」に貼り、新しいキャラか直すキャラを選んで「取り込む」 |
| `oshi/<key>.png` | 「表情ごとの絵」の、その表情の「絵を選ぶ」 |
| 切り分けていない表の画像 | 「表情ごとの絵」の「1枚の表から切り分ける」(行と列を選び、マスごとに表情を選ぶ) |
| 緑一色の背景の絵 | 「緑の背景を抜く」を入れてから「絵を選ぶ」 |

- 「表情ごとの絵」は、キャラができてから出ます。新しいキャラなら、先に JSON を取り込んでもらいます
- 取り込みの検査は番頭がします。断られたら、出た理由 (「知らない口調です」「せりふは1つ60字まで」など) に
  合わせて JSON を直し、もう一度貼ってもらいます
- 絵は PNG・JPEG・WebP・GIF の 1MB まで。名前は20字まで
- 絵と名前は入れ物 (Drive のフォルダ) に置かれ、Drive で共有している人は直に開けます。見られて困る絵は入れないよう伝えてください
