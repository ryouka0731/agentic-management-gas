# 番頭 (VS Code 拡張)

SoftBanto (通称 番頭) の様子を VS Code に出す拡張です。手元の道具 (kit) と同じく、Google Drive for desktop で同期した
**命令の入れ先** (`queue/`) でやりとりします。鍵もトークンも要りません。外のサービスにはつなぎません。

## できること

- **やること**: 左の「番頭」の一覧に、自分が担当の open なやることを期限の早い順に出します。押すと題名・期限・本文が出ます。
  一覧の上の「更新」で取り直します
- **あなたの番**: 数分ごと (`banto.pollMinutes`) に、確かめてほしい確認依頼・戻ってきた確認依頼・期限の近いやることを見て、
  増えたものを知らせます (開いた最初は、あるものをまとめて1つ)
- **推し**: ステータスバーに、いま使う推しの名前と一言を出します (取り直すのは1時間に1回まで。番頭で推しがオフなら出ません)
- **会議に入る**: 今日の予定を1日の始まりと30分ごとに取り、始まりの1分前に「◯◯が始まります」を「入る」付きで知らせます。
  `banto.meetings.autoOpen` をオンにすると、押さなくても始まりに会議の URL (Google Meet) を開きます。同じ予定で二度は開きません。
  始まって5分を過ぎた予定は、知らせも開くのもしません

## 入れ方

1. 番頭の画面の右上の自分の顔 →「手元から動かす道具を落とす」で zip を落として解凍し、`node agent.mjs setup` の案内どおり
   `agentkit.json` (命令の入れ先 `queueDir`) を作る
2. 拡張を入れる。どちらか:
   - このフォルダで `npx @vscode/vsce package` を実行して `.vsix` を作り、VS Code の「拡張機能」→「…」→「VSIX からのインストール」で入れる
   - このフォルダを VS Code で開き、「実行とデバッグ」の「拡張機能の開発ホスト」(F5) で動かす
3. 設定の `banto.kitDir` に、1 で解凍したフォルダを入れる

## 設定

| 設定 | 既定 | 内容 |
|---|---|---|
| `banto.kitDir` | `""` | 手元の道具を解凍したフォルダ。中の `agentkit.json` の `queueDir` を使う。空なら `~/.agentkit.json` か `~/.banto/config.json` を見る |
| `banto.email` | `""` | 自分のアドレス。やることを自分の担当で絞る (空なら open なものを全部) |
| `banto.pollMinutes` | `5` | あなたの番を何分ごとに見るか |
| `banto.meetings.autoOpen` | `false` | 会議の始まりに、押さなくても会議の URL を開く |
| `banto.oshi.show` | `true` | ステータスバーに推しの名前と一言を出す |

## 気をつけること

- 番頭のキューは1分ごとに回るので、返事まで1〜2分かかります。知らせも同じだけ遅れます
- **予定が読めるのは、命令の入れ先を動かしている人 (キューを仕掛けた人) のカレンダーと、その人に共有されて登録されている
  カレンダーだけです。** ほかの人は「あなたの予定を読めません」になり、会議の知らせは出ません
- 予定の返事 (今日の題名と会議の URL) は、受け取ってすぐ消すまでのあいだ、命令の入れ先を共有している人に見えます
- 会議の URL は、予定の「場所」か「説明」に `https://meet.google.com/…` が書いてあるときだけ拾います。開くのは
  `https://meet.google.com/` と `https://calendar.google.com/` の URL だけです (入れ先は共有している人なら書けるため)

## 作り

素の JavaScript (CommonJS)。依存はありません。

| ファイル | 中身 |
|---|---|
| `extension.js` | vscode の API を触る薄い層 (一覧・知らせ・ステータスバー・設定) |
| `lib/app.js` | 動き (15 秒ごとの見張り、取り直す間隔、会議の知らせと開く) |
| `lib/logic.js` | vscode に依らない決まり (返事の読み方・知らせる時刻・二度開かない・URL の取り出し) |
| `lib/queue.js` | 命令の入れ先の探し方と、命令の置き方・結果の拾い方・片付け方 |

テストは `node --test kit-vscode/test/*.test.js` (リポジトリの根から)。
